# Harness v0.2.114

Stable desktop patch release for macOS, Windows and Linux.

## Dictation starts

- The composer's microphone failed with "text realtime output modality
  requires realtime v2" on every Codex CLI. Dictation now asks Codex for a
  voice session it accepts, so your words appear in the draft as you talk.
  Codex's voice is still never played.

## Switch tabs by number

- ⌃1 to ⌃8 show that chat tab, and ⌃9 the last one, as in browsers.
  ⌘1 to ⌘9 still open the first nine chats in the sidebar.
- On Windows and Linux, where Ctrl and a number opens a sidebar chat, tabs use
  Alt and a number.
- ⌘K → New chat now opens a new tab, like ⌘T and the + button, instead of
  replacing the chat you were in. ⌘T replaces ⌘N as the New chat shortcut;
  a shortcut you set yourself is kept.
- Closing a tab returns to the tab you were on before it, not its left
  neighbour, so ⌘T then ⌘W puts you back where you started.

## New projects start where you keep them

- New Project opens in the folder you usually add projects from on that
  device. Set a different one in Settings → Files → **New project starting
  folder**, or go back to automatic.

## Sign another computer in to ChatGPT

- Settings → Accounts can now sign a different computer's graff in to
  ChatGPT from the desktop you're using. OpenAI's page opens in this
  computer's browser, and Harness passes the sign-in back to the other
  computer, which finishes it. Your tokens stay on the computer that runs
  graff.
- If the sign-in can't be caught automatically, paste the address the browser
  lands on into the dialog.
- Both computers need this release. An older one still asks you to finish the
  sign-in in its own browser.
- iPhone: graff's ChatGPT sign-in can be reconnected from the phone, in an
  in-app browser, instead of only on the computer that runs graff.

- graff's ChatGPT sign-in counts as signed in only when it grants plan usage.
  A sign-out or a sign-in without plan usage no longer shows as connected,
  and signing out keeps graff's app registration, so the next sign-in skips
  the consent step.

## Messages no longer stop the agent's own work

- A message that arrived while an agent was busy with work it started itself,
  such as a background task or subagent finishing, used to cancel that work.
  graff now takes the message straight away and answers once it finishes.
  Other agents get it as soon as they go quiet. Nothing is cancelled.
- When graff finishes a turn it started itself, the chat now stops showing
  Working, its timer stops, and queued messages go ahead, without an
  interrupt.

## Agent questions stay in their pane

- In a narrow split pane, an agent's question stays inline down to a much
  smaller pane. Below that, **Answer** opens the question beside its pane
  instead of over the whole window, so the other panes stay usable. Escape or
  a click outside closes it and keeps your answer.

## iPhone

- **+** on Home opens a picker with a **Search projects** field, matching a
  project's name, folder or computer. The project you're in is listed first.
