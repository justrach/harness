# Harness v0.2.92

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.91](v0.2.91.md) is included.

## Attachments

- The paperclip, drag and drop and paste now attach any file, not just images.
  A PDF, log or source file shows as a file card and reaches the agent as a
  file it can open. Folders and files over 24 MB show a notice.

## Tabs and splits

- ⌘D leaves every pane the same size. Closing a pane keeps an even split even;
  sizes you dragged are kept.
- Opening a chat that another pane already shows moves focus to that pane
  instead of swapping panes around.
- A new-session pane or tab keeps the project you picked for it when you switch
  away and back.

## Sessions

- Scroll to bottom goes away once you click it.
