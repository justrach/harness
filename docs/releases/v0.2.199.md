# Harness v0.2.199

## Desktop

- **Polished Zen workspace and topbar alignment.** The Zen sidebar and workspace pane sit in matching `rounded(12)` inset surfaces with muted dark and warm light contrast, Codegraff default styling, and matching rounded Settings cards without duplicate back controls. The active topbar session pill aligns flush with the right workspace card edge across sidebar open/close transitions.
- **20-scene composable Codegraff × Ensō Founder member cards.** Member cards in Settings → Account combine 20 layered Japanese scenes, 20 ASCII sky gradients, 8 Ensō brushstrokes, 5 holographic finishes, and 8 Hanko seals (`128,000` combinations; `3,200` 1-of-1 three-layer artworks). Members `#000·001` through `#001·000` display `#d4a64a` Founder gold borders, member-number pills, and `Founder 1/1 · <TITLE>` edition status synced across Edge, Rust (`harness-proto` / `harness-engine`), and Nano.
- **First-run coding CLI onboarding.** Detects missing Claude Code and Codex CLIs during initial setup and provides inline install actions, live progress states, and autonomy defaults before entering a workspace.
- **In-chat Before & After design comparisons.** `show_before_after` pairs render inline inside chat replies with Side-by-side and draggable Split scrubber modes, controlled by the Appearance setting toggle (enabled by default).
- **Restored capsule effort sliders and header popovers.** Compact ASCII capsule reasoning sliders use per-model accents for OpenAI and Claude models, alongside updated header Updates and footer Account Usage popovers.

## Verification and scope

- **Native and portable Nano suites:** `zig build test` passed **1,144** tests with **3** skipped plus **28** `native-math` Rust unit tests; the portable card-scenes check (`-Dportable=true -Dtest-filter="card scenes"`) passed **11** tests. Both `cargo check --release --locked -p harness` and `ReleaseSafe` `harness-nano` builds succeeded with `0.2.199` embedded in the binary, and `cargo metadata --locked` confirmed all **15** workspace crates resolve to **0.2.199**.
- **Edge and Rust crates:** Edge `typecheck` passed along with **22** unit suites (**243** tests) and **13** `workerd` suites (**47** tests), including `member-profile` trait derivation and fallback compatibility when database columns from the companion schema migration are not yet present. Targeted Rust suites passed for `harness-proto` (**105** tests), `harness-mcp` (**58** tests), `harness-theme` (**33** tests), `harness-engine` (**25** `auth::tests` + **13** `uploads` tests), and `harness` CLI (**4** `auth_cli` tests).

Synthetic fixtures and scripted renders cover the Zen pill alignment, all 20 member card scenes, CLI onboarding states, before/after comparison cards, and effort sliders. Unrelated LSP and native-extension panel work remains separate from this release.
