# Harness v0.2.197

## Desktop

- **Latest actions come first.** Expanded tool groups show the newest action at the top, so a long run no longer hides its current Read, Edit or command at the bottom. Disclosure state and tool identity survive new arrivals; saved transcript data remains chronological.
- **Read the current reply from the top.** A new live turn gets room below it and is positioned near the top of its pane instead of being pushed against the composer and chased to the bottom as it grows. Manual scrolling stays under the reader's control; **Scroll to bottom** remains an explicit way to follow incoming output.
- **GitHub code review looks like a diff.** File cards have file-type icons and separate addition/deletion counts. Expanded patches reuse the numbered, colored source renderer, with horizontal scrolling instead of wrapping code into prose. Rename, binary/omitted-patch and truncation notices remain available.
- **macOS window controls line up.** Native traffic lights use the custom toolbar's vertical center rather than AppKit's shorter default titlebar center.

## Verification

The current-reply top-anchor and newest-first tool-order regressions fail against the pre-fix source and pass with these changes. Focused tests exercise growing replies, manual scroll ownership, explicit bottom-follow, appended tools and preserved detail controls. The combined native suite passed 1,086 tests with 3 skipped; the portable suite passed 1,085 tests with 4 skipped. The ReleaseSafe frontend build passed, including the GitHub diff and titlebar polish.

No foreground desktop interaction or OS-observed traffic-light capture is claimed. LSP, native-extension panels and unrelated account/sidebar work are excluded from this release.
