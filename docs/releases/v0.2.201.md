# Harness v0.2.201

## Desktop & ACP

- **Codegraff ACP accounts, plan usage windows, and separate-limit models.** Adds `_codegraff/usage` and enriched `list_graff_logins_with_usage` tracking across `harness-proto`, `harness-adapters`, `harness-engine`, and `harness-nano`, surfacing per-provider plan usage windows (`Session`, `Week`, `Credits`, `Fable`) and model-specific separate-limit indicators in accounts and model pickers (`#878`).
- **Native extension panels in Settings → Agents → Extensions.** Exposes `ListNativeExtensions` and `InvokeNativeExtension` across `harness-rpc`, `harness-adapters`, `harness-engine`, and `harness-nano`, with local project selection, 5-second open-page refresh, equal-width stat tiles, side-by-side worker subcards, and semantic status indicators (`#876`).
- **Bundled `harness-github-runners` macOS observability plugin.** Ships a standalone Zig 0.17 Native Extensions ABI v1 binary (`Contents/Resources/bin/harness-github-runners`) that parses UTF-8 BOM `.runner` configs, tails runner `stdout.log` for active and recent jobs, inspects macOS `libproc` worker process trees (`CPU%`, `RSS`, heavy-build lock PID, root disk free), and exposes `refresh`, `pause`, and `resume` cloud-fallback controls (`#876`).
- **Outside-floating 3D Member Card & Settings → Account redesign.** Moves the signed-out and signed-in Member Card outside onto an unclipped ambient sky stage with full 3D perspective turn, hover lift, parallax depth layers, and one-shot deal-in foil sweep; replaces the sky dither and foil pattern with original non-ASCII Seigaiha wave-crest silkscreen, sunago gold-dust stipple, and Kumiko star-lattice foil finishes; and structures Settings → Account into grouped rows with the primary action outside below.

## Verification and scope

- **Workspace and CI suites:** `cargo metadata --locked` verifies all **15** workspace crates resolve to **0.2.201**, alongside Lean 4 `FrameSchedule` / `Tween` telemetry proofs, full `harness-nano` `zig build test` and `zig build test-visual` runs, and targeted `harness-proto`, `harness-doc`, `harness-adapters`, and `harness-engine` Cargo suites.
