# Harness v0.2.201

## Desktop

- **Native extension panels in Settings → Agents → Extensions.** Exposes `ListNativeExtensions` and `InvokeNativeExtension` across `harness-rpc`, `harness-adapters`, `harness-engine`, and `harness-nano`, with local project selection, 5-second open-page refresh, equal-width stat tiles, side-by-side worker subcards, and semantic status indicators.
- **Bundled `harness-github-runners` macOS observability plugin.** Ships a standalone Zig 0.17 Native Extensions ABI v1 binary (`Contents/Resources/bin/harness-github-runners`) that parses UTF-8 BOM `.runner` configs, tails runner `stdout.log` for active and recent jobs, inspects macOS `libproc` worker process trees (`CPU%`, `RSS`, heavy-build lock PID, root disk free), and exposes `refresh`, `pause`, and `resume` cloud-fallback controls.

## Verification and scope

- **Workspace and CI suites:** `cargo metadata --locked` confirmed all **15** workspace crates resolve to **0.2.201** atop `b0e5ffbae`, where `Cursor compatibility`, `UI tests` (`macos-runner`, `ui-tests`, `session-sync-regressions`, `macos-frame-recovery`), `Windows tests`, and `Attribution` passed alongside offscreen `ui.Tester` and Zen `snap` coverage for `Settings › Agents › Extensions`.
