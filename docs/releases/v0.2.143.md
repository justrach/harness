# Harness v0.2.143

Desktop release for macOS, Windows and Linux, with clearer update status and
safe remote scheduling for managed headless hosts.

## Unattended host updates

- Managed headless installations keep updating automatically without an open
  desktop viewer. Downloads happen before the host waits for active chats and
  open terminals to finish. Activity is checked again immediately before
  installation, with no further network wait between that check and restart.
- Desktop Settings → Devices now shows each supported computer's installed
  and latest versions, automatic-update preference, progress, waiting state
  and errors. Update checks target the selected computer, not the viewer.
- **Update when idle** queues one update on a managed host. Closing the viewer
  does not cancel it, repeated requests coalesce, and requesting one update
  does not turn automatic updates back on if they were disabled.

## Existing desktop safeguards stay in place

The normal desktop app retains its automatic downloads and optional idle
restart. Active chats, open terminals, unsaved edits and unsent composer input
continue to block an automatic restart. Remote controls do not force a desktop
app to restart or bypass its local settings.

Older hosts must upgrade before exposing the new remote controls. Source and
package-managed installations still use their original update method; the
phone UI is unchanged.
