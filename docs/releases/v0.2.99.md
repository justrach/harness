# Harness v0.2.99

Pairs with Codegraff `graff` v0.0.302.9. Developer ID signed, notarized and stapled.
Everything in [v0.2.98](v0.2.98.md) is included.

## Performance

- Split chat panes that aren't changing reuse their last frame instead of
  redrawing, so one busy chat no longer makes every open pane repaint. Text
  selection still works in those panes.
- Hit-testing and macOS text layout in the UI framework are faster, lowering
  CPU use while agents stream.

## Browser pane

- graff's rendered pages and MCP App results open from their tool chip in a
  browser-pane tab on macOS. Each tab is sandboxed: no network, no saved data.
  Linux and Windows show a notice for now.
