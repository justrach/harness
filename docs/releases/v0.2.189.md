# Harness v0.2.189

## Highlights

- **OpenCodex Light and Dark.** A new independently authored, Codex-inspired theme family pairs neutral surfaces with blue accents. Both appearances are available in the shared mobile catalog and Nano's desktop catalog. Existing theme selections are unchanged.
- **Quieter working chats in Nano.** Parsed Markdown and syntax spans are reused until source text, language or palette changes. Completed off-screen rows use their measured-height spacers while another session is working, rather than rebuilding every message for a sidebar spinner. Selection and prompt-rail navigation retain their existing behavior.
- **Lower animation overhead.** Visible working indicators request at most two whole-window redraws per second, with a slower cadence in unfocused windows. New input and streamed content still invalidate immediately; this is not a streaming-rate limit.
- **Updater build compatibility.** Nano's updater passes its I/O handle to the engine-discovery function introduced in v0.2.188.

## Verification

Synthetic regressions for issue #814 cover unchanged-text parsing and highlighting, working-indicator cadence, off-screen row construction, and cache invalidation/lifetime. The original parsing and cadence regressions fail on the pre-fix main revision. The theme suite checks catalog synchronization, provenance and contrast.
