# Harness v0.2.146

Desktop update for macOS, Windows and Linux.

## Typing an answer to "Branch changed" continues the chat

- When a chat's checkout has moved to another branch, Harness asks how to continue before sending. Typing a reply there ("go on", or your next instruction) used to bring the same question back every time, so the chat looked stuck until you picked an option.
- A typed reply now continues on the branch the question showed. Your text is sent along with the messages that were waiting, and the agent is told the branch changed.
- If the branch moves again after the question appears, Harness still asks again for the new branch instead of continuing, and keeps what you typed.
