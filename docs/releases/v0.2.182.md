# Harness v0.2.182

## Highlights

- **Sidebar `Last activity` filter accuracy (`1d`, `3d`, `7d`, `30d`, `All`) (`apps/nano/src/view_sidebar.zig`, `apps/nano/src/view_sidebar_menus.zig`, `apps/nano/lean-proofs/Nano/FrameSchedule.lean`)**:
  - Previously, `prepareItems` only filtered `.idle` (`•`) conversations by `last_activity`, allowing unread/unseen historical conversations marked `.completed` (`✓` where `last_seen_ms < last_message_ms`) and pinned rows (`visiblePins`) outside the selected window (such as `4d`, `1w`, `3w`, `4w`, `1mo`) to remain visible when `1d`, `3d`, `7d`, or `30d` was active.
  - Both `prepareItems`, `visiblePins`, and `activityCount` now keep only active live sessions (`.working` and `.awaiting_input`) or conversations whose `timeMs()` falls within the selected `LastActivity` window, formally verified in `FrameSchedule.lean` (`fixed_filter_hides_completed_and_idle_outside_window` and `fixed_filter_keeps_live_or_in_window`).
  - Moving the pointer diagonally across intermediate filter rows (`Compact`, `Archived`) into the open `Last activity` submenu card no longer closes the submenu prematurely, and clicking a group header row cleanly toggles its submenu.
- **Composer expand (`⤢`) button reliability & 120Hz Write page transition (`apps/nano/src/view_composer.zig`, `apps/nano/src/view_write.zig`, `apps/nano/lean-proofs/Nano/FrameSchedule.lean`)**:
  - Previously, `view_write.zig.button` was mounted conditionally on `focused or draft.items.len > 0`. In an attachment-only draft (`shape == .expanded` with empty text), pressing `mouseDown` on `composer-write` caused `ui.textField` to blur `c.focus = 0`, unmounting `composer-write` on the `mouseUp` frame before `clicked()` could fire (`old_write_button_unmounts_on_attachment_only_press`).
  - The expand button is now mounted unconditionally whenever the composer is in its expanded layout (`fixed_write_button_survives_focus_blur`), uses `kit.iconButton` (`pressFeedback` + pointer cursor), clears `focus_composer` when opening the full-window Write editor so focus stays inside `write-field`, and animates `write-page` with a 120Hz `ease_out_cubic` entrance transition.
- **CI workflow reliability (`apps/nano/src/tests_ui_glass.zig`, `.github/workflows/codegraff-sync.yml`)**:
  - `tests_ui_glass.zig` now skips the native translucent shell pixel probe on Linux where `surface_palette.zig` intentionally renders an opaque shell (`alpha = 255`).
  - `.github/workflows/codegraff-sync.yml` now installs Zig `0.17.0` (`mlugg/setup-zig@v2`) before running `scripts/package-macos.sh`.
