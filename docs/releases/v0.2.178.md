# Harness v0.2.178

`harness-nano` is now the desktop app across macOS, Windows, and Linux, replacing the Rust GPUI client (`crates/ui` and its vendored `zui` / `gpui-component` forks), with 120Hz word-by-word streaming dissolve veils, live inline-Markdown balancing, background desktop self-updates, and `ReleaseSafe` runtime checks. Built on v0.2.176.

## Desktop (`harness-nano`)

- **Cache-tracked `build_info.version` & self-updater loop protection ([ADR 0008](../adr/0008-release-verification-and-update-safety.md), `apps/nano/build.zig`, `apps/nano/src/view_updates.zig`, `scripts/package-macos.sh`)**:
  - `apps/nano/build.zig` now embeds `../../Cargo.toml` via `WriteFiles.addCopyFile` so Zig's build runner hashes `Cargo.toml` on every build instead of caching an older version string across releases.
  - `classifyUpdateOutput` (`apps/nano/src/view_updates.zig`) only marks `app_ready = true` when `harness update` swaps a new bundle (`"relaunch Harness to finish"`), and clears `app_ready` when `harness update` reports `"is up to date"`.
  - `shouldRelaunchOnDeliver` ensures background update staging (`relaunch_when_ready == false`) never auto-exits an active window on launch; it surfaces `"Restart to update"` in the sidebar and `Settings › Devices` until clicked.
  - `scripts/package-macos.sh` now verifies that both `Contents/MacOS/harness` and `Contents/MacOS/harness-nano` embed the exact `$VERSION` from `Cargo.toml` and runs a 3-second isolated live launch check before notarization.
- **Desktop self-updater & `Settings › Devices` update card (`apps/nano/src/view_updates.zig`, `apps/nano/src/view_settings_devices.zig`)**:
  - Background release manifest checks stage desktop app updates via `harness update` and surface the `#sidebar-update-row` badge (`Update to v{version}` / `Downloading v{version}…` / `Restart to update`) in the bottom-left sidebar footer as soon as a newer release is available.
  - `Settings › Devices` wraps the local version header and the `"Restart automatically to install updates"` toggle row (`#restart-to-install-updates`, persisted as `restartToInstallUpdates`) in a rounded settings card with an interactive right-hand action pill (`Update to v{version}`, `Restart to update`, `Downloading…`, `Check for updates`).
  - Remote devices running an older Harness version show `"Update available · Details"` in the device list.
- **Upward composer footer popovers & `Select ref` branch picker (`apps/nano/src/view_menus.zig`, `apps/nano/src/view_tab_strip_menus.zig`, `apps/nano/src/requests.zig`)**:
  - Bottom-docked composer footer chips (`New worktree`, `Select ref`, and `Run on: This Mac`) now open their popovers **upward** above the anchor (`upwardOrBelow`) when near the bottom edge of the window so menu rows never clip off-screen.
  - Clicking `Select ref` on a git project fetches branches via `ListRefs` (`#branch-popover`), lets you pick a base branch (`From {ref}`), and passes `worktree.base` when starting a new session.
- **Model picker & reasoning page polish (`apps/nano/src/view_picker.zig`)**:
  - Top-edge clamping (`header_height + 6`) keeps the `Starred`, `graff`, `Claude Code`, and `Codex` agent tabs strictly below the `38pt` window titlebar even in short windows or mid-window composers.
  - Grouped model rows now render maker icons, compact context window pills (`500k`, `1M`, `200k`), `Plan` subscription badges on section headers, and a `28pt` keyboard-hint footer bar (`↑↓ Navigate`, `↵ Configure`, `esc Close`).
  - The model detail card and reasoning configuration page feature surface-tinted maker icon tiles, spec pills, a high-contrast `26pt` capsule reasoning slider with `1pt` border definition in both light and dark appearances, and an accented reasoning badge.
- **Transparent tab cap inverse-circle shoulders (`apps/nano/src/view_panel_chrome.zig`)**:
  - Replaced the `2×r` box mask on active tab cap shoulders with a `1pt` foot border erase (`y = -1`) and cached concave SVG wedge fills/strokes (`panel-shoulder-fill-l/r`, `panel-shoulder-edge-l/r`), keeping the titlebar area outside the concave curve 100% transparent without dark rectangular box artifacts or `1px` border steps.
- **120Hz word-by-word streaming dissolve, line-wrap spring glide & offscreen scroll/resize culling (`apps/nano/src/veil.zig`, `apps/nano/src/view_transcript.zig`, `apps/nano/src/view.zig`)**:
  - Incoming assistant and reasoning text commits to layout immediately while dissolving a paint-only `1 - (1 - p)^1.6` opacity veil across newly arrived words and staggering multi-word bursts left-to-right.
  - Unclosed trailing inline Markdown markers (`**bold`, `*italic`, and `` `code ``) on the active streaming line are auto-balanced in flight (`balanceStreamingMarkdown`).
  - Streaming line wraps now glide smoothly at 120Hz (`scroll_cap` spring + `settle_y` on the transcript column) instead of snapping existing lines upward by one line height on the wrap frame.
  - Offscreen transcript turns use width-tracked cached heights (`cached_h` / `cached_w`) across trackpad scrolling, live window resizing, streaming, and `⌘B` sidebar tweens so scrolling and resizing run at a locked 120Hz without re-parsing or re-shaping offscreen Markdown.
- **Narrow split-pane transcript bounds across `⌘B`**: `columnWidth` and `paneWidth` (`apps/nano/src/view_transcript.zig`) and split-neighbor sizing (`apps/nano/src/view.zig`) clamp the transcript column strictly inside the available pane width minus gutters across `⌘B` sidebar tweens and split panes.

## iOS

- **Workspace & Settings redesign**: Updated `WorkspaceView`, `SettingsView`, `ChatRowView`, and `ChatScreen` with smooth spring transitions, refined session canvas headers, and clean grouped settings rows.
