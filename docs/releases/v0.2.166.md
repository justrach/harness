# Harness v0.2.166

Restart into an update whenever you like.

## Updates

- When an update has downloaded, a "Restart to update" row appears at the bottom of the sidebar. Harness still restarts into updates on its own when nothing is going on, but with agents working all day that moment might not come, so the row lets you do it yourself. With the sidebar hidden, the restart button is in the titlebar.
- The × on the row hides it for that version. The update still installs the next time Harness restarts.
