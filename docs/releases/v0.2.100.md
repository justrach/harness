# Harness v0.2.100

Stable release for macOS, Windows and Linux. Includes the changes in
[v0.2.99](v0.2.99.md).

## Project picker

- The sidebar project dropdown lists projects on connected devices first,
  followed by projects on disconnected devices under an **Offline** caption.
  Search ranking and name ordering are retained within each group, and the
  caption does not add a keyboard-navigation stop.

## Conversations and connections

- Import conversation history from Claude Code, Codex and graff.
- Recover more reliably when a sign-in refresh response is lost.

The composer project picker is unchanged. Mobile app and terminal-client
packages are distributed separately from this desktop release.
