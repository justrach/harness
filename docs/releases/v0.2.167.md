# Harness v0.2.167

Messages to a busy graff chat arrive while it works, and fixes for selection, the changes card, the project picker and the close warning.

## Agents

- When one chat messages a graff chat that is busy on this Mac, the message now goes to that chat's peer inbox, so it can read it mid-task instead of waiting until its whole turn ends. Idle chats, other agents and chats on other devices work as before. Back-and-forth between two busy chats still stops after four hops; a message from you to a chat starts its count over. Needs graff 0.302.70 for chats Harness reopened. (#729)

## Desktop

- The changes card grows to fit its text at narrow widths and large text sizes, and keeps the Review button and line counts readable. (#726)
- The warning about closing a running session goes away on its own after five seconds. (#723)
- The project picker highlights one row at a time and works fully from the keyboard. (#699)

## iOS

- Text in agent replies can be selected and copied with a long press. (#695)
