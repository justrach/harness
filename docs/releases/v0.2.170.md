# Harness v0.2.170

A session on the Mac can now hold several panels of chats, browser pages, files and terminals, closed chats are recoverable, and chats no longer stop to ask about their branch. Thanks to Phil Hedayatnia for the workspace work behind most of this release. (#714)

## Desktop

- A session holds independent panels and tabs, so chats, browser pages, files and terminals stay together, and switching sessions or moving a tab between windows keeps your drafts. Each empty panel has its own device selector.
- Sessions and files drop onto panels, including empty ones and browser panels. Releasing a tab past the window's edge opens a new window with that tab, and File → New Window (⌘N, Ctrl+N elsewhere) opens one directly.
- A closed chat is recoverable: ⌘⇧T reopens it, and Chat history can restore it, hide it, or delete it for good after asking. A sidebar click or notification for a chat open in another window goes to that window instead of opening a second copy.
- The project sidebar has an all-projects view and a "Needs you" section. The task view is an option in Settings. A blank tab saved during a freeze no longer comes back as a session nobody opened.
- Chats no longer stop to ask "Branch changed" or "Shared checkout". Your message goes straight out and the agent is told the branch moved. That also means two chats in one folder can end up on each other's branch with only the agent told, so give parallel work its own worktree. A question already open in an older chat still works, and your next message closes it.
- The "files changed" card above the message box is gone. ⌘R or the titlebar button shows or hides Changes beside the chat, with Discard all and Done reviewing.
- Diffs can hide whitespace-only changes, and selecting text in a reply offers Reply, which quotes it in your message.
- New sessions keep the Chat | Code switch, now in the message box's footer, and a Chat offers only the Auto models. Sessions can have an emoji or icon, and there are new Warm Harp Light and Dark themes.
- The expanded message editor has Send now and Save in its top toolbar. Saving returns the draft and its attachments to the message box.
- ⌘[ and ⌘] move between panels, ⌘S saves the file on screen, and ⌘D, ⌘⇧D and ⌘⇧W work on a terminal in a panel. ⌘L and the model picker move to the panel with the message box when a terminal or file has focus.
- Off macOS, Ctrl+O and Ctrl+N reach a focused terminal.
- Hovering and typing cost less with several panels open, and answering a question no longer freezes the window.
- Images you sent no longer repeat under the reply when the agent reads them, and the Archived option stays in Show options while Compact is on.
- Thinking text scales with ⌘+ and ⌘−, along with the reply around it. (#740)

## iOS

- Model thinking shows as Thought process chips in the tool group around it. (#742)
- Settings gains Keep awake while agents work and an attach sound, an archived session can be hidden from the shelf on this phone, and the project pill offers No project. (#744)
- A long import no longer blocks the main thread while a session opens. (#762)
