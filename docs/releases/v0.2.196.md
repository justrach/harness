# Harness v0.2.196

## Desktop

- **Screenshots keep their proportions.** macOS image previews now agree with EXIF rotation metadata instead of squeezing a landscape screenshot into a portrait-shaped box. Small rotated images are upright too.
- **GitHub belongs to the chat that opened it.** Its split pane and tab sit beside their parent chat, with a distinct GitHub header and parent label. Changing focus preserves repository and pull-request navigation. Explicitly opening GitHub from another chat reparents the existing single surface.
- **Click pictures to inspect them.** Assistant reply pictures, Markdown images and sent chat attachments open a chat-owned preview with zoom, drag, Fit, Close and Escape. GitHub description and activity images have the same inspection controls in their own pane. Previews reuse the existing host-jailed or validated image caches rather than making another request.
- **Questions stop taking over unrelated panes.** Interactive question cards follow the active chat, without a window-wide modal scrim. Unfinished answers and attachments survive focus changes, and waiting chats are highlighted in the sidebar and tabs.
- **Fast scrolling rebounds at the bottom.** Precise native momentum gets one bounded spring response instead of an abrupt stop; subsequent momentum does not keep pumping the bounce. Discrete wheels and Reduce Motion retain their non-inertial paths.
- **Native Antigravity ACP.** Harness can launch `agy acp`, preserving explicit overrides and legacy ACP-server support. The agent updater offers **Check and update** for the same selected native CLI, without claiming a newer version is known or updating arbitrary custom servers.

## iOS

- **The Duo sessions drawer moves with the chat.** The complete cover-display page, including Back, slides left during the reveal. Search, selection and dismissal retain the existing navigation stack. The current Duo keyboard/inset fixes are preserved, and ordinary iPhones keep their normal navigation.

## Verification

The screenshot-orientation, native-CLI detection, updater, question-focus, GitHub placement/image-click and momentum-impact regressions fail without their corresponding fixes. Focused native headless desktop suites and the ReleaseSafe frontend build passed, including full-tree/culled pixel comparison during bounce and image orientation/pixel checks. After integrating current main, 30 Duo, 6 iPhone Pro and 6 Pro Max simulator tests passed for navigation, copy, keyboard insets, portrait/landscape composer reachability and draft retention.

Final feature-head CI passed Windows UI/engine/packaging, iOS recovery/parity, macOS UI/frame-recovery, Linux/macOS networking and Android checks. Native Windows foreground GUI coverage was skipped.

No signed-in Antigravity provider turn, live CLI update, foreground desktop interaction or physical-iPhone test is claimed. Rust binary size-profile measurements remain experiments; this release does not switch optimization profiles, remove features or widen analytics collection.
