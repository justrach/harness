# Harness v0.2.195

## Desktop

- **See GitHub screenshots inline.** Pull request and issue descriptions and activity now render native image previews instead of only image labels. Markdown images and native-parsed HTML image tags keep their layout and declared widths, with readable loading and unavailable states.
- **Bounded, isolated image loading.** Preview requests use GitHub-owned HTTPS origins and validated redirects, without cookies, saved credentials or transcript attachment/filesystem access. Downloads are capped at 4 MiB, four simultaneous requests, sixteen retained previews and a 15-second request deadline. Closing a panel or changing its repository retires its previews safely; late responses cannot mutate the new panel. Inaccessible or unsupported images keep their alt text.
- **Automatic installation is on by default.** Supported installed macOS apps check hourly, including after sleep, and install verified updates in the background. Settings → Devices → Install updates automatically turns this off; an explicitly saved off choice remains off. Updates never restart the app automatically or interrupt running chats. Other installation types continue to check and report availability without attempting unsupported installation. `HARNESS_AUTO_UPDATE=0` still disables automatic installation.

## Verification

Focused native image-rendering/cache tests, HTTP streaming and redirect tests, provider-Markdown isolation tests and updater/settings tests passed. The ReleaseSafe desktop build passed. Image transport also cross-compiled for Linux and Windows; native rendering snapshots and HTTP delegate tests use synthetic data. Live private-image authentication and live installation/restart were not exercised.
