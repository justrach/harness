# Harness v0.2.191

## Highlights

- **Native Git history and changes.** Browse checkout history, stage or unstage individual files, and review explicit commit and push confirmations without leaving the native desktop. Commits use the index and your configured Git identity; unstaged edits remain untouched. Push uses an existing upstream and never force-pushes. Git mutations currently run on Unix hosts; unsupported hosts refuse them without changing files.
- **Repository-wide GitHub browsing.** Switch between session-related pull requests and the repository's pull requests or issues. Inspect summaries, changed files, bounded patches, and activity in native views, with Open on GitHub available for the full context. Reads use the host's existing GitHub CLI authentication.
- **Less work while scrolling long conversations.** Warm, settled transcripts build nearby rows and preserve offscreen space instead of rebuilding every reply on each wheel frame. Native selection and copy retain their full-content path. A synthetic 160-reply benchmark reduced average wheel-frame CPU work from 1.81 ms to 0.11 ms and nodes from 5,310 to 474; these measurements are not an end-to-end 120 FPS guarantee.
- **Interactive native visuals on desktop and iPhone.** Generated visual artifacts can contain bounded native text, statistics, charts, buttons, toggles, and sliders. Interactions update temporary local state without another model call. The runtime limits execution time, memory, tree size, and text; it has no file or network access.
- **A ready-to-run isolated demo.** The source-control demo creates a synthetic repository and mock conversation, exercises real local-engine history pagination, and can capture native snapshots without using an account or altering your working repository.
- **Leaner Rust paths and optional headless builds.** Transcript and workspace processing avoid unnecessary copies. Preview and visual dependencies remain enabled for ordinary desktop builds, while explicit no-default-feature builds can omit them.
- **Window and iPhone polish.** Collapsed-sidebar titlebar controls keep their clearance. The iPhone header shows the session's working folder, flat Duo headers avoid overflow, and crash reports improve MetricKit frame offsets and signal headlines.
