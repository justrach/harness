# Harness v0.2.187

## Highlights

- **A main bot that works across projects (`crates/engine/src/bots.rs`, `crates/engine/src/bots_reports.rs`, `apps/nano/src/bots.zig`, `apps/nano/src/view_bots.zig`, `apps/nano/src/view_bots_work.zig`, `docs/bots.md`)**:
  - Bots are still experimental and off until the `Experimental: Bots` switch in Settings › Agents is turned on. With it off nothing here runs or draws.
  - Turning Bots on now gives you one **main bot**, named `main`, when the device has none: the one thread you keep for every project. Ask it for something in any project and it starts that piece of work as an ordinary chat in the project it belongs to, tells you in one line what it started, and ends its turn. It asks only when it cannot tell which project you mean. Needs graff 0.302.74.62 or later; with an older graff the primary bot keeps its earlier text and starts no chats.
  - **It hears back.** When a chat the main bot started finishes a turn nobody typed, stops on a question, or fails, the engine puts one message into the main bot's thread with the chat, its project and its last words, and the main bot tells you what came back. A turn you type in that chat yourself is yours and is not reported.
  - **The chain is bounded.** A report starts a turn of the main bot, and that turn can start more work. Work started while the main bot was answering a report is a step further from what you asked; nothing past the third step is reported, and the third report says it is the last. One chat is reported at most four times an hour, and at most twenty reports go out in ten minutes.
  - The main bot is first in the Bots group, with the chats it started that are still going or have something to read under it, each with its project. Its page has **In progress**, **Scheduled** (every bot's routines, soonest first) and **Completed**. The catch-up names a chat it started by what it is and where.
  - Your other bots are helpers: each keeps one job, and the main bot hands a request to the one whose job it is.

## Limits

- What the main bot is told is text given to a model. The engine does not stop it from working in its own thread, or make it ask before a step that cannot be undone. A started chat's approvals are its own.
- A chat the main bot started is listed under the main bot, not among the project's sessions.
- It starts work in projects Harness already knows. For a folder that is not a project it has to be told the path.
- Nothing is kept on disk for the reports. An engine that restarts does not report what ended before it started; the catch-up still shows it.
