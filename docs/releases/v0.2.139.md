# Harness v0.2.139

Desktop release for macOS, Windows and Linux: answering an agent's question
no longer risks stopping the run you just answered.

## Agent questions

- For a moment after the question panel closes, a click or tap on Stop is
  ignored. The panel's Submit sits where Stop appears once the run goes on,
  so a double-click on Submit, or one more tap on the phone while the answer
  syncs, used to stop the agent before it acted on your answer (#149).
  After 1.5 seconds Stop works as usual. `/stop`, Esc-to-stop and Cancel
  question are unchanged.
- The same rule ships in the iOS and Android apps, which take it in their
  next builds.

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
