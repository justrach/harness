# Harness v0.2.173

Tabs and links behave the way they did before the panel system again, with the panel layout kept. Built on v0.2.172.

## Desktop

- A link opens beside the chat at the old side pane's width. In a split it was squeezed to an equal share of the row, which could leave the page tiny. Files and diffs get the same width.
- One close removes the page and gives the chat its room back. It used to leave an empty panel you had to close as well.
- With a chat focused and a page, file or diff beside it, ⌘W closes that first and leaves the chat on screen. It used to close the chat.
- Closing a tab goes back to the tab you were on before, not the one that slid into its place.
- Closing the only tab in a window moves on to a new chat. It used to stop on an empty "New panel" page that nothing could close, which sent you to the sidebar's "Close session" dialog.
- Each slot in the split top bar has its own ✕ under the pointer, so a "New tab" slot can be removed in one press. Narrow slots close from their ▾ menu.

## For harness-nano

`docs/nano-tab-behaviour.md` lists these rules and what to change in nano to adopt them.
