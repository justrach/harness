# Harness v0.2.152

Desktop update for macOS, Windows and Linux.

## The context card counts tool output

- Hovering the context ring now splits what the agent reads into files, commands and search, as the card intended. Before, every tool result was counted as "System & other", so a long Claude Code chat looked like almost all system. Chats pick this up for tool results from now on.

## The agent work card matches your theme

- The steps chip and its card use your theme's accent and surfaces instead of a fixed pink and fixed greys in dark mode. Blue, amber and red still mark status.
