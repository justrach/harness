# Harness v0.2.181

`harness-nano` is now the desktop app across macOS, Windows, and Linux, replacing the Rust GPUI client (`crates/ui` and its vendored `zui` / `gpui-component` forks), with 120Hz word-by-word streaming dissolve veils, live inline-Markdown balancing, background desktop self-updates, and `ReleaseSafe` runtime checks. Built on v0.2.180.

## Desktop (`harness-nano`)

- **Markdown table column floor & prose-demand capping (`apps/nano/src/view_markdown.zig`)**:
  - Added per-column longest-word and minimum-width floors (`columnWidthsWithWords`, `longestWordWidth`) and capped per-column unwrapped paragraph demand at the table width so multi-sentence prose columns never crush label columns into mid-word character wrapping in split panes.
- **Right-pane slot & `Cmd + D` folder menu alignment across global tabs (`apps/nano/src/view_tab_strip_render.zig`, `apps/nano/src/tests_ui_strip_folder_search.zig`)**:
  - Kept horizontal split-pane header slots aligned to their pane columns even when additional top-level workspace tabs are open, so pressing `Cmd + D` always places the new split slot and its `Search folders…` popover directly above the new right pane instead of over the left pane.
- **Flush-left / flush-right selected tab cap seam fix (`apps/nano/src/view_panel_chrome.zig`)**:
  - Backed the outer `1pt` border column with `k.background` across the `foot - r .. foot + body_radius` join and extended `panel-selected-cap-shadow` across the flush edge so the leading edge of the first tab cap joins into the panel body without a `1pt` inward step or shadow pinch.

## iOS

- **Zeron-style unified Model + Thinking Tier capsule, compact Thinking Tier card, and Steer/Queue toggle (`apps/ios/Harness/Composer/ComposerView.swift`, `apps/ios/Harness/Views/NewSessionView.swift`, `apps/ios/Harness/Views/ReasoningSlider.swift`, `apps/ios/Harness/Models/MessageQueue.swift`, `apps/ios/Harness/Markdown/MarkdownBlockView.swift`, `apps/ios/HarnessTests/MessageQueueTests.swift`)**:
  - Unified the composer model and thinking-tier triggers into a single Zeron-style `[ (mark) Model  Tier ]` capsule (`ZeronModelTierPill`), upgraded `TraitPickerSheet` and `ReasoningTrack` with the bold tier header, tappable `Model ›` subtitle to switch directly to `ModelPickerSheet`, and `40×30` pill thumb over a `28pt` capsule track, added the `Steer` / `Queue` composer chip (`ComposerSteerChip`, defaulting to Steer on Codex and GPT-6.0+), and raised the Markdown table cell minimum width floor (`112pt`).
