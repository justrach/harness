# Harness v0.2.172

⌘T starts a chat straight away, ⌘D asks which folder the new chat is in, and the Tool Access Map shows real numbers. Built on v0.2.171.

## Desktop

- ⌘T starts a new chat in the focused panel, with the cursor in it. The + buttons still open the page of other things a tab can be.
- ⌘D (and ⌘⇧D) opens the new panel with its folder list showing. Type to narrow it and press Enter, or press Esc to stay in the same folder and start typing. With no projects it goes straight to the chat.
- The folder list in the top bar has a search box, and a long list scrolls under it instead of running down the window.
- A new chat's folder dropdown is back on the chat box, next to Code, with the same search. ⌘⇧P opens it.
- One ⌘W now closes a split panel when its last tab closes, and takes you back to the panel beside it, instead of stopping at an empty panel first.
- The Tool Access Map counts the whole chat and keeps up while it runs. It read "0 calls" whenever the latest turn had no tools or the chat was in another panel.
- Its lines now go to the tools actually used. Web search no longer gets a line when it wasn't used, and a subagent's tab no longer shows the chat's tools as its own.
- The map's Replay and Edit input buttons are gone. They ran nothing: Replay showed a made-up success. A tool's list now opens on its latest call, and you can click any recent call to see its input and output.
- An open Tool Access Map with nothing running no longer keeps redrawing.
