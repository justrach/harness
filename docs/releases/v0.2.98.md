# Harness v0.2.98

Pairs with Codegraff `graff` v0.0.302.9. Developer ID signed, notarized and stapled.
Everything in [v0.2.97](v0.2.97.md) is included.

## Sessions

- Claude sessions can start with Chrome: turn on **Chrome** in the model
  options, next to Fast Mode and Thinking, and the agent gets the browser
  extension's tools.
- Cursor chats now see your own MCP servers and plugins.
- A chat that briefly drops out of the list comes back to its pane instead of
  turning into a blank new session.
- Copy a session's working-directory path from its Copy menu.
- Open a terminal from the new-chat screen (Cmd/Ctrl+J), in the selected
  project's folder.
- Discard all uncommitted changes from the Changes pane, with a confirmation;
  it refuses while an agent is working in that tree.

## Models and accounts

- The model picker marks each model on the graff and opencode tabs with its
  maker, and lists your own plan logins first, then local models, hosted
  credits and your own keys, each section saying which.
- Sign in to graff's providers from Settings → Accounts.
- Browser sign-ins show the sign-in link with a Copy button, so you can finish
  in another browser or on another machine.
- Signing in again to an account stuck on "Authentication failed" now replaces
  its dead login, and Remove account on a live login signs that CLI out
  (Claude keeps its shared MCP sign-ins).

## Projects and settings

- In New project, the back arrow goes up one folder, as the left arrow key
  does, and Add project is the primary button.
- Settings reopens on the section you last viewed.
- Your appearance choice is shared with the Harness phone app, which can match
  this desktop's theme.

## Updates and networking

- Update checks now run hourly and catch up right after your Mac wakes from
  sleep.
- Packaged apps honor the operating system's proxy settings.
