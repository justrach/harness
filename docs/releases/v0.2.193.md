# Harness v0.2.193

This desktop release includes the improvements prepared for v0.2.192, whose desktop publication was stopped by a reproducible preexisting queue race. The v0.2.192 tag is retained unchanged.

## Highlights

- **Reliable queued messages during concurrent delivery.** Local queue appends, edits, moves, removals and takes serialize their compound list operations. An automatic drain can no longer invalidate an append position, fail a queue request or make a removal target the wrong row. Queue publication releases the mutation guard before notifying subscribers.

- **The command you typed comes first.** Exact slash-command matches take priority over longer prefixes, so `/compact` is selected before `/compact-at`. Both commands remain available. Slash suggestions also retain readable backgrounds in light and dark themes.
- **Updates are information, not errors.** Expected update/restart recovery notices use a neutral presentation instead of a red Error card; actual run failures keep their error treatment.
- **GitHub links open where you choose.** Transcript PR and issue links can open the exact item in Harness's native GitHub panel, including closed items and other repositories. Code links open the Code view. Settings → Links & browsing saves your preferred destination; explicit browser actions remain available.
- **Settings are easier to find.** Search recognizes tasks such as GitHub links, updates, privacy and text size. Results include descriptions and a clear action. The section list scrolls separately from search and Back, and section breadcrumbs show where you are.
- **More readable native GitHub views.** Repository descriptions and activity render bounded native Markdown, while clearer hierarchy and empty states make repository browsing easier to follow. Provider content cannot load remote images or execute HTML.
- **Smoother scrolling and less sidebar work.** Desktop transcripts gain bounded bottom rubber-banding. On iOS, scrolling up while a reply streams no longer confuses content growth with a gesture to follow the bottom. Project grouping avoids repeated full-list scans during sidebar transitions. These are workload improvements, not a universal frame-rate guarantee.
- **Readable questions across split panes.** Agent questions stay usable in narrow layouts through a window-bounded surface, rather than squeezing option text into a tiny pane. Workspace-title hover bubbles no longer cover the conversation.
- **Hourly update checks without interruptions.** The desktop checks for releases hourly, including after sleep. Checks do not automatically install updates, restart the app or interrupt active agents; installation remains an explicit action.
- **Optional anonymous responsiveness metrics.** A separate, off-by-default setting can share bounded aggregate frame/scroll measurements by coarse platform/version/renderer/pane-count cohorts. It excludes conversation content, paths, account data and installation identifiers. Recording uses fixed-size counters and a nonblocking single-slot handoff to a background worker. Lean policy proofs cover bounded work and publication rules, not zero CPU cost or end-to-end latency.
