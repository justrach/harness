# Harness v0.2.112

Stable desktop patch release for macOS, Windows and Linux.

## See which computer and version sent each request

- When graff runs in Harness, its requests to the Codegraff gateway now say
  which Harness version launched it and which computer it ran on. The usage
  page on codegraff.com shows both on each request, next to graff's own
  version.
- The computer appears under the name it has in Harness. Renaming it on that
  computer takes effect for the next graff session.
- This needs graff v0.0.302.28 or later. A `GRAFF_HOST_APP` or
  `GRAFF_DEVICE_NAME` already set in your environment is kept, and
  `GRAFF_CLIENT_TAGS=off` stops graff sending either.
