# Harness v0.2.180

`harness-nano` is now the desktop app across macOS, Windows, and Linux, replacing the Rust GPUI client (`crates/ui` and its vendored `zui` / `gpui-component` forks), with 120Hz word-by-word streaming dissolve veils, live inline-Markdown balancing, background desktop self-updates, and `ReleaseSafe` runtime checks. Built on v0.2.179.

## Desktop (`harness-nano`)

- **Zeron-style compact thinking tier picker (`apps/nano/src/view_picker.zig`, `apps/nano/src/model_picker.zig`, `apps/nano/src/app_agent.zig`, `apps/nano/src/view_composer.zig`)**:
  - Clicking the composer model chip opens directly onto the Zeron-style compact Thinking Tier card (`High`, `GPT-6.1-Sol ›`, fast-tier bolt toggle, and the `28px` capsule effort slider with `44×32` pill thumb) without requiring a second click;
  - Dragging or clicking any stop on the compact slider updates the reasoning tier live (`applyLiveModelAndReasoning`) and rolls the header badge and composer chip text in real time;
  - Clicking the model subtitle row (`GPT-6.1-Sol ›`) smoothly expands the card upwards (`ScalarTransition` at 120Hz) into the full searchable model list, with a `←` back control in the tab strip and automatic return to the compact card after picking a model.
- **Lean 4-verified mid-frame arena & string retirement (`apps/nano/lean-proofs/Nano/FrameSchedule.lean`, `apps/nano/src/workspace.zig`, `apps/nano/src/model_picker.zig`, `apps/nano/src/view_composer.zig`, `apps/nano/src/wizard.zig`, `apps/nano/src/prompt_history.zig`, `apps/nano/src/app_question.zig`, `apps/nano/src/app_drafts.zig`, `apps/nano/src/composer_defaults.zig`, `apps/nano/src/app_panels.zig`, `apps/nano/src/app_actions.zig`, `apps/nano/src/app_agent.zig`, `apps/nano/src/view_menus.zig`, `apps/nano/src/view_settings_devices_updates.zig`, `apps/nano/src/app.zig`, `apps/nano/src/view.zig`)**:
  - Formally proved in Lean 4 (`FramePhase`, `AllocState`, `mid_frame_free_invalidates_measure`, `deferred_retire_preserves_measure_and_paint`, `reap_at_frame_start_safe`) that any arena or string slice borrowed by `.text` nodes during `view(a, c)` must outlive `ui.layout.measure` (`TextSystem.layout` / `Wyhash.update`) and `paint`;
  - Fixed a use-after-free in `view_composer.zig` where `modelChip` captured `label_text = a.modelLabel(t.model)` (from `a.models.arena` at offset `0x34af`) before `b.clicked()` called `togglePicker` -> `ensureModels` -> `copyModels(&a.models, ...)` and freed `a.models.arena`, then passed the freed `label_text` into `kit.rollText` and crashed in `TextSystem.key` / `Wyhash.update`;
  - Replaced immediate mid-frame `arena.deinit()` and `gpa.free()` calls across `workspace.List.replace`, `model_picker.copyModels`, `wizard.deinit`, `prompt_history.clear`, `app_question.close`, `app_drafts.clear`, `composer_defaults`, `app_panels.chatChanged`, `app_actions.onSnapshot`, `app_agent`, `view_menus.ensureRefs`, `view_settings_devices_updates`, and `App.syncPeers` with deferred retirement queues (`retireArena`, `retireSlice`) reaped before widget tree construction.
- **Automatic replacement of older `harness headless` daemon on update (`apps/nano/lean-proofs/Nano/FrameSchedule.lean`, `apps/nano/src/view_updates.zig`, `apps/nano/src/engine.zig`, `apps/nano/src/engine_start.zig`)**:
  - Proved `older_engine_triggers_auto_replace` in Lean 4 and updated `Engine.onEngineInfo` and `restartIntoUpdate` so when an updated `Harness.app` connects to a locally managed `harness headless` daemon running an older version, it automatically terminates the stale daemon process (`killStaleLocalHeadlessProcesses`) and spawns the updated `harness headless` binary instead of showing the manual `harness daemon stop` banner.
- **Settings `← Back [esc]` button & Escape key fix (`apps/nano/src/view_settings.zig`, `apps/nano/src/view_settings_accounts.zig`, `apps/nano/src/view_settings_theme_import.zig`, `apps/nano/src/view.zig`)**:
  - Fixed `Escape` key handling when `settings-search-field` has focus (`c.shortcut(.{ .key = S.escape })` and `c.input.key == .escape`) and ensured clicking `← Back` (`#settings-back` / `#settings-top-back`) always closes Settings and returns focus to the composer.
- **Steer-by-default on GPT-6.0+ & Codex and composer Steer/Queue toggle (`apps/nano/src/app_queue.zig`, `apps/nano/src/view_composer.zig`, `apps/nano/src/view_newchat.zig`, `apps/nano/src/view_session_footer.zig`, `apps/nano/src/view_queue.zig`, `crates/engine/src/registry.rs`, `crates/harness/src/acp/mod.rs`)**:
  - Follow-ups sent during an active turn now default to **Steer** on GPT-6.0+ models and Codex, with a live `Steer` / `Queue` toggle chip in the composer footer (#787).

## iOS
