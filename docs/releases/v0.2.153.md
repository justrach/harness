# Harness v0.2.153

Desktop update for macOS, Windows and Linux.

## Sign graff in to Claude Agent from Accounts

- Settings → Accounts has a Claude Agent row under graff. Signing in lets graff run Claude models through your own Claude Code login. If Claude Code isn't signed in yet, Harness walks you through the Claude Code sign-in first and then finishes the graff side for you.
- The model picker names the section "Claude Agent" with the Claude mark, instead of the raw `claude-agent` id.
- Needs graff 0.302.61 or later; Harness's own graff updates to it automatically.
