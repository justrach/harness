# Harness v0.2.101

Pairs with Codegraff `graff` v0.0.302.13. Developer ID signed, notarized and stapled.
Everything in [v0.2.99](v0.2.99.md) is included.

## Terminal UI

- `tui/` adds a terminal UI that runs on Harness's agents, so any agent the desktop
  app can drive works from a terminal. It is Codex's terminal UI on a bridge that
  speaks Codex's app-server protocol over Harness's adapters, with the Codegraff mark
  in the header, command and file-edit rendering with diffs, and slash commands the
  bridge can't serve hidden.
- The model picker opens from a cached list instead of asking every agent first.
- macOS (Apple silicon) and Linux (x86_64, aarch64) tarballs, `harness-tui-<version>-<os>-<arch>.tar.gz`,
  are attached to this release. Unpack and run `bin/harness-tui`. It needs `python3` and `nc`.
  There is no Windows build yet.
- Agents' edit and write calls now carry their old and new text on the opening tool call,
  which is what lets the diff draw as the call starts.

## Conversations from other tools

- `/resume` now also lists conversations that Claude Code, Codex and graff kept on this
  device. Picking one imports it as a chat and opens it, and "Import N conversations from
  other tools" brings in all of them. An import keeps your prompts, the agent's replies and a
  row per tool call; tool arguments and full outputs are not copied. Importing twice does
  nothing, and sessions Harness started are not offered again.

## Cloud sandboxes

- A cloud sandbox can sign in to Harness as its owner's device with a lease token
  (`HARNESS_SANDBOX_TOKEN_FILE`), so `harness headless` runs there without a browser.

## Sign-in

- A refresh whose reply was lost can be asked again instead of signing you out.
  iOS tells a rejected sign-in from an unreachable server.

## Phone apps

- The Android app is in the repo: Kotlin and Compose, with the same screens, themes and
  shared rules (`apps/parity`) as iOS.
- iOS keeps unsent drafts per chat, gathers pinned sessions above groups, opens the home
  list newest-first, lets you swipe between running sessions with a "Now" strip on Home,
  and keeps the agent list in the model picker while a device is unreachable.
- A "Bring in your agent" onboarding screen on both phone apps.
