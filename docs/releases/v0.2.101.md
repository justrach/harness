# Harness v0.2.101

ChatGPT authentication failures now offer **Sign in to ChatGPT** directly in the desktop and iPhone transcript. Recovery runs on the session's execution device, not whichever device is currently selected in the viewer.

Legacy Codex recovery supports phone approval: open the official ChatGPT device sign-in page, enter the one-time code, and approve. The execution device polls and saves the renewed credentials; OAuth tokens do not pass through the phone. Device-code authorization must be enabled in the account's ChatGPT security settings.

The newer `chatgpt-new` provider still requires browser completion on the execution desktop. Its direct-plan authorization does not support the Codex device grant, so Harness does not substitute credentials or silently change providers.

The failed message is not automatically replayed. Sign-in recovery does not claim to fix upstream token renewal. Existing generic errors and older transcript documents remain readable without offering an untrusted login action.
