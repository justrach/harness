# Harness v0.2.101

Stable patch release for macOS, Windows and Linux. Includes the changes in
[v0.2.100](v0.2.100.md).

## Agents

- Choosing a model on an agent that offers each model in several
  thinking-level variants no longer stalls the run waiting for the selection.
  Harness picks the requested variant, confirms both the model and the thinking
  level before sending the prompt, and reports a mismatch instead of running on
  a different model.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
