# Harness v0.2.142

Desktop release for macOS, Windows and Linux.

## Background chat panes

- Visible, unfocused chat panes coalesce streaming text and passive animation
  updates to roughly 10 Hz. The focused pane stays responsive, and clicking,
  scrolling, selecting text and switching focus remain immediate.
- Hidden panes pause presentation work and catch up when shown. Agents and
  incoming data continue normally; idle panes do not gain a polling loop.

## Composer and titlebar

- Keep the last written text readable when trailing whitespace soft-wraps onto
  additional visual rows. Whitespace, caret movement and scrolling are preserved
  (#591).
- Keep the titlebar's new-chat button visible on draft tabs and space the update
  controls evenly, without shifting them after the first prompt or overlapping
  the sidebar divider (#593).

## Independent chat checkouts

- New coding sessions use independent worktrees by default, including new tabs
  and split panes. A selected base is passed through to worktree creation (#594).
- Older conversations sharing a primary checkout offer a choice before
  continuing: use an independent checkout from the recorded committed snapshot,
  or explicitly keep sharing. Uncommitted shared work is not copied or moved,
  and existing independent worktrees remain in place.
- Correct the Windows process-input type used when creating a worktree, so the
  same isolation path builds on Windows as well as macOS and Linux.

This release retains the Claude credential-refresh protection shipped in
v0.2.141 (#599). Update the computer running your chats; if its Claude login is
already invalid, sign in there again. A phone-only update cannot repair the
host's credentials.
