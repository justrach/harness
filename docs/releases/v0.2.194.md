# Harness v0.2.194

## iOS

- **Switch sessions from the Duo cover display.** A sessions button sits directly below Back in the right-side navigation rail. It opens a searchable drawer over the current chat while leaving a narrow strip of that chat visible. Pick a session to switch, tap the strip or Close to return, or start a new session from the drawer. The existing inner-display layouts and other iPhones keep their current navigation.
- **Copy complete replies in one tap.** Sent prompts and completed assistant replies have a timestamp and copy control. Copy preserves the full authored Markdown—including paragraphs, lists, links, code and line breaks—without copying thinking, tool traces or attachment transport metadata. A checkmark confirms the copy.
- **Native visuals work with message footers.** Visual-ending replies use the same footer handling as text and image rows. This resolves the compile integration between native visual rows and whole-message copying; executable visual scripts are not copied as reply text.

## Verification

The final current-main iOS build and 42 focused tests passed on an iPhone Duo simulator running iOS 27.1, including drawer navigation/search, button placement near Back, non-Duo exclusion, visual-tail footer states, and actual prompt/reply copy-paste. All screenshots and UI fixtures use synthetic data.
