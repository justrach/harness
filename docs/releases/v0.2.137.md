# Harness v0.2.137

Desktop release for macOS, Windows and Linux: Mermaid diagrams in agent
replies draw as diagrams, sidebar session search handles the keyboard
properly, links in subagent panes open from the right chat, and two composer
fixes for slash-command completion and the scroll fade.

## Chats

- A ```` ```mermaid ```` block in an agent's reply draws as a diagram, like
  it already did in Markdown file previews. While the reply streams, the
  block shows as code until its fence closes, then renders once, off the
  main thread, and is cached so scrolling and repaints don't redo it. The
  block's header switches between the diagram and its source and copies the
  source; a click opens the diagram full size. Diagrams follow light and dark
  mode and scale to fit narrow panes. If the renderer can't read the source,
  you get the code block with a short note.
- Links in a subagent's pane open from the chat that owns them, including a
  child opened from a parent pane that wasn't focused. Closing a child tab
  revokes its link actions, even from a menu that was already open, and a
  reopened child gets working ones (#456).

## Sidebar

- Session-name search only treats bare keys as search actions: ⌘↵ or a
  modified arrow no longer opens or moves through results. Focus, result
  visibility and row styling are fixed (#492).

## Composer

- Tab-completing a slash command typed in front of existing text keeps that
  text: `/goal|prompt text` + Tab gives `/goal prompt text` instead of
  deleting `prompt` (#575).
- The composer only fades its top or bottom edge while written text is cut
  off there. Trailing blank lines below the last line no longer wash it out
  (#578).

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
