# Harness v0.2.96

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.95](v0.2.95.md) is included.

## Performance

- Local preview discovery (finding the dev servers your projects run) no longer
  scans every process and open file on the machine each pass. It looks at
  listening sockets first and inspects only those processes, so the background
  CPU Harness uses while a project is open drops substantially. Discovered
  previews are unchanged.

## Agent questions

- Questions stay usable in narrow and short panes: options wrap instead of
  clipping, and long answers scroll.
