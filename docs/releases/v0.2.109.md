# Harness v0.2.109

Stable desktop patch release for macOS, Windows and Linux.

## Desktop updates install themselves

- When a new Harness release is available, the desktop app downloads it in
  the background. The sidebar shows **Update ready — restart now or it
  installs on quit**: click to restart into it now, or keep working and the
  next launch runs the new version.
- Harness never restarts on its own, so running chats and terminals are not
  interrupted. A quit cancelled by unsaved files installs nothing.
- A failed download shows its error and can be retried with a click; a newer
  release is tried again automatically.
- Set `HARNESS_AUTO_UPDATE=0` to keep updating manually. Headless installs
  keep their existing opt-in behavior.
- This applies from v0.2.109 onward: updating to this release itself still
  takes one click.

## Graff engine updates are visible

- Harness checks for a new stable graff engine hourly and whenever a graff
  chat starts (at most once every ten minutes), instead of every six hours.
- A card in the bottom-right corner reports the update, with **What's new**
  for the release notes. New chats use the new engine; open chats keep their
  current session. Dismissing a version hides it until a newer one ships.
- With graff auto-update turned off, the card offers **Update** instead.
- A graff selected with `GRAFF_EXECUTABLE` and beta installs are left alone.

## Graff signs in with Harness

- Signing in to Harness can also sign in the `graff` command line when it has
  no key on the device. An existing graff key is never replaced, and sign-in
  continues unchanged if a key cannot be issued.

## Sidebar and panes

- Pane cards show each agent's icon, and drop the conversation preview on
  hover and the misleading project line under each card.
- The titlebar **+** opens a new tab, like Cmd+T.
- Hovering a model setting previews its options; the first click pins them.
- Clicking an inactive pane's transcript controls activates that pane.

## graff-observe

- New `graff-observe` command line, built from source with
  `cargo install --path crates/observe` (not yet included in the release
  packages), for reading graff's local run traces and
  session transcripts without modifying them: per-run and total token, cache,
  latency, tool-failure and sub-agent statistics; live `watch`; and an `xray`
  of tool-output sizes.
- `graff-observe otel` exports runs as OpenTelemetry traces to the endpoint
  set by the standard `OTEL_EXPORTER_OTLP_*` variables. Nothing is sent unless
  you run the export.
