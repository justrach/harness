# Harness v0.2.162

Write long messages on a full page, and open your computer's local dev servers on your phone.

## Write in full screen

- A long message gets its own page. Click the expand button on the composer, or press Cmd+Shift+E (Ctrl+Alt+E on Windows and Linux), and the chat pane turns into a document: a serif page with a comfortable line length, a word count, and "Aa" to switch to sans.
- Markdown styles itself as you type. Headings, lists, bold, italic, inline code, quotes and code blocks are set in place, and the `#` and `**` marks stay visible but faint, so what you send is exactly what you typed.
- It's the same draft as the composer. Done or Esc gives the text back unchanged; attachments, `@` files and `/` commands work on the page too. Cmd+Enter or Send sends it.
- On iPhone, the expand button on the composer opens the same page as a full-height sheet.

## Localhost on your phone

- A local dev server on your computer can be opened on the phone. Tap a `localhost` link in a chat and choose "Open on this phone": the computer loads the page in a private headless browser and streams it to the phone, where you can scroll, tap and type.
- Only `http` and `https` addresses on this computer are allowed. The browser uses a fresh profile, keeps at most 8 pages, and stops after a minute with no viewer.
- It needs Chrome, Edge, Brave or Chromium on the computer. New windows, file pickers, downloads and the clipboard aren't supported yet.
