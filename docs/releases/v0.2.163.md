# Harness v0.2.163

A faster, quieter desktop app: smoother scrolling at your display's full refresh rate, less work while you type, and no drawing when nothing changes.

## Smoother and lighter

- Scrolling and animations run at the display's full refresh rate on macOS 14 and later (120 Hz on ProMotion), and frames stop entirely when nothing on screen changes.
- A spinner in a window you aren't using wakes the app 30 times a second instead of at the display's rate, and animations throttled to 30 fps now actually reach 30.
- Typing in the composer no longer redraws the chat, and a streaming reply no longer redraws the composer, so keystrokes take about half the time in a long chat.
- Spinners, context rings and history lanes reuse the shapes they drew on the frame before instead of rebuilding them.
- Jumping to a row (search results, agents, the rail) glides once per display frame instead of in 60 Hz steps.
- On Windows, an idle window no longer draws a frame on every vsync; it draws only when something asks for one.
- A few unused libraries and image formats are gone from the build.

## Jump to an agent

- In the agents card on the composer's footer, click an agent to scroll the chat to where it was started. Its chip gets a brief ring so you can spot it, and clicking the chip still opens the agent's own tab.

## iPhone Duo

- On the cover display, the chat uses the full width beside the system's vertical bar, the context card fits on screen above its ring, and the transcript ends above the running turn's chips instead of showing through them.
