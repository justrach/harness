# Harness v0.2.164

A fix for flickering in the desktop app's composer.

## Fixes

- A question from the agent and queued messages no longer flicker or fade in and out while their chat is the active pane. Since v0.2.163, the composer reuses its last frame when nothing in it changed, and that lost the state of their entrance fade, so the fade restarted on each redraw. The composer still skips the work it skipped in v0.2.163.
