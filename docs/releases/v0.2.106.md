# Harness v0.2.106

Stable patch release for macOS, Windows and Linux.

## ChatGPT reconnect verification

- A successful ChatGPT sign-in now completes reconnect even when Graff adds
  model-selection and usage guidance after its success message. Previously,
  Harness could incorrectly report that sign-in did not grant plan access
  despite the browser confirming success.
- Recovery still requires a newly saved credential and an explicit report that
  ChatGPT plan usage is enabled. Denied plan access remains an error; provider,
  account routing, drafts and conversation-resume behavior are unchanged.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
