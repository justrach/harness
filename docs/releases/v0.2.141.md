# Harness v0.2.141

Desktop release for macOS, Windows and Linux.

## Claude account usage

- Fixes a path where checking saved Claude account usage could rotate
  credentials still held by Claude Code (#599). Harness now only refreshes a
  saved account when the live login is readable and belongs to a different
  account with a different refresh token. If the identity or credentials
  cannot be confirmed, it leaves the token alone.
- Phone **Usage** is serviced by the computer running your chats. Update
  Harness on that computer to get this fix; a phone-only TestFlight update
  cannot deliver it.
- If Claude chats already report an authentication failure, sign in to Claude
  again on the computer running them after updating. The update cannot restore
  invalidated credentials.
