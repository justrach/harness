# Harness v0.2.111

Stable desktop patch release for macOS, Windows and Linux.

## Graff's compaction point sits in the graff row

- Settings → Agents shows **Compact context at** inside the graff row, next to
  graff's other controls, instead of in a separate card below the agent list:
  Default (80%), or 50, 60, 70, 75, 85 or 90%.
- The setting is unchanged: it applies to graff chats started after the
  change, and `/compact-at 70` still changes one open chat.

## Dragging a session into a split opens it

- Dragging a session from the sidebar onto **Open to the right** or **Open
  below** sometimes did nothing. The drop targets disappeared mid-drag when
  the session list or pins updated, which happens often in a synced
  workspace. They now stay up for the whole drag.
- Dropping a session over an existing pane no longer switches to that pane's
  conversation instead of opening the one you dragged.

## Motion

- Settings → Appearance → **Reduce motion**: System, On or Off. System follows
  the operating system's accessibility setting on macOS, Windows and Linux.
- **Pause animations in background** (off by default) stops spinners and
  shimmer while Harness isn't the focused window, so a working session in the
  background no longer keeps the window redrawing.

## Settings are easier to find

- A search box at the top of the Settings sidebar finds sections, individual
  settings (including common synonyms such as "dark mode" or "keybindings")
  and every keyboard shortcut by name. ↑/↓ move through results, Enter opens
  one and Escape clears the search.
- The sidebar groups its sections under General, Agents, and Devices and
  data, and Appearance is split into labelled groups.

## Faster and lighter

- `/resume` no longer redraws the whole sidebar on every key, so typing and
  arrowing through the palette stays quick with many conversations.
- A subagent streaming under a quiet parent conversation saves its progress
  once per window instead of on every event.
- On Linux, long-running Harness returns freed memory to the system once a
  minute instead of letting it build up.

## Terminal

- Slow trackpad scrolling over a terminal now moves it; small movements used
  to be rounded away.

## TUI

- Typing a message while a turn is running steers that turn instead of
  closing the TUI with a `turn/steer` error.

## Phones

- iOS and Android get Settings → Agents → **Graff compaction**, the same
  setting as the desktop's graff row, read and written on the computer that
  runs graff. A computer on an older Harness asks you to update it there.
