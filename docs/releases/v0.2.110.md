# Harness v0.2.110

Stable desktop patch release for macOS, Windows and Linux.

## Choose where graff compacts a conversation

- Settings → Agents has a new **Graff compaction point** card. It sets how
  full the model's context window gets before graff compacts a conversation:
  Default (80%), or 50, 60, 70, 75, 85 or 90%. Lower keeps each request
  smaller and cheaper; higher keeps more of the conversation word for word.
- The setting applies to graff chats started after the change. To change one
  open chat, type `/compact-at 70` in it (graff 0.0.302.27 or later).
- A `GRAFF_COMPACT_PCT` you set yourself still takes precedence.

## The graff update card says what changed

- When the graff engine updates, the card lists what the update brings: the
  "What's new" lines of every release since your previous version, up to
  four, then how many more are in the release notes.

## Long-running work

- A background agent that outlives the turn that started it no longer has its
  session ended under it 30 minutes after the chat goes idle.
- On Linux, an idle checkout no longer re-scans its changes every half second.
