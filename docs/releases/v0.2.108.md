# Harness v0.2.108

Stable desktop patch release for macOS, Windows and Linux.

## Cancel pending questions safely

- Pending agent questions now offer **Cancel question**, without supplying an
  answer or treating dismissal as approval. Cancellation stops the owning turn
  and pauses queued delivery; it never replays a prompt or completed tool.
- Stale requests cannot cancel newer turns. Unanswered orphaned questions can
  be cleared without starting a replacement turn.
- MCP clients can request the same cancellation with `dismiss_input` on hosts
  advertising `dismiss-input-v1`.

## Edit images on queued messages

- Queued rows offer **Add images**. Their existing edit flow supports adding,
  removing and replacing staged images without sending the message.
- Queue editing remains available while an agent question is pending. Saving
  or cancelling the edit preserves the question's selections and the original
  composer draft and attachments.
- A file picker opened for one queued row cannot attach its results to a
  different draft after navigating away.

## Delegated context and honest usage reporting

- Compatible graff agents can forward `run_task` context diagnostics over ACP.
  Harness shows how many UTF-8 bytes were supplied and used, and whether graff
  summarized the reference. It does not inherit the parent transcript, rewrite
  context, or change the configured provider, account or billing route.
- Only small diagnostic fields sync to other desktop devices; task answers and
  caller context are not copied into those fields. Replayed metadata updates
  the existing row instead of creating duplicate accounting entries.
- Per-task usage and settled charges are **unavailable** from graff's current
  print-mode runner. Harness displays that limitation, never a zero-dollar
  charge or estimated list-rate amount. Provider account usage remains the
  authoritative billing record; these diagnostics add nothing to its totals.
- Older agents without the ACP metadata continue working without diagnostics.

## Nonblocking agent-to-agent waits

- Harness MCP callers running inside a chat receive an immediate status
  snapshot instead of blocking their own conversation on another agent.
  Replies still arrive asynchronously. External clients retain bounded waits.
- Explicit wait snapshots return the newest assistant message, not the entire
  historical transcript. This does not change graff's shell-wait behavior.

## ChatGPT and Anthropic sign-ins

- Settings → Accounts now names graff's own ChatGPT sign-in plainly
  **ChatGPT**, and the separate Codex login **ChatGPT (old Codex)**. The row
  most people want used to be the one carrying a qualifier ("ChatGPT (new)")
  while both read as ChatGPT. Labels only: same credential and flow, no change
  to the agent or model a conversation uses.
- **Sign in with Anthropic** in Settings → Agents starts `graff login
  anthropic` on the device selected there and reuses the Accounts dialog, so a
  phone can begin a sign-in that finishes on the desktop. Like the ChatGPT plan
  sign-in, the callback must complete in the browser on the execution device,
  so its authorize URL is never relayed. The Claude Code login stays untouched:
  this is an Anthropic subscription through graff, not another Claude Code
  account.
- ChatGPT can be reconnected from the iPhone. The phone asks the execution
  device to start the sign-in with its browser muted, signs in itself, and
  sends back only the loopback callback it landed on. The host accepts just
  that sign-in's own callback and state and exchanges the code with its own
  verifier, so tokens stay on the host.

## Messages during a running turn

- A message that arrives while an agent is running a turn it started itself — a
  background task or subagent finishing — no longer cancels that work. Graff
  answers the message once the turn ends.

## Phone and desktop layout

- Error chips wrap their message below the header on iOS and Android, and the
  iOS question panel scrolls long choices while the answer field and buttons
  stay in view.
- Tapping the session header on iPhone renames the session; the name is shared
  across devices.
- The model picker's agent tabs are labelled and scroll, and Ctrl+Tab cycles
  agents without taking Tab from the search field.

## Performance and diagnostics

- A CLI whose `--version` probe is slow — the first run after an update, while
  macOS scans it — no longer loses its PATH precedence to an older install, and
  the timeout is no longer cached like a failure.
- An idle subagent no longer keeps the session commit timer firing, so the
  adapter's polling loop stays quiet on a settled conversation.
- Anonymous performance stats now include the desktop process's own CPU and
  physical footprint on macOS, split by workload: empty, settled small, settled
  large, and streaming. Samples cover this process and the engine it embeds,
  never child agents or conversation content.

## Linux

- Arch Linux packages (`.pkg.tar.zst`) are published for x86_64 and aarch64,
  and the x86_64 package is installed with `pacman -U` on a real Arch container
  before a release ships. Pacman installs are not self-updated: reinstall the
  package for each release.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
