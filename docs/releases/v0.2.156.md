# Harness v0.2.156

Desktop update for macOS, Windows and Linux, and a new iOS build on TestFlight.

## A calmer home and sidebar

- The sidebar starts with **New chat** and **Search chats**, and groups chats into Needs you, Today and Earlier. That grouping is the new **By status** option and the default; your other organization options are still there.
- Home asks "What should Graff do?" above one composer, with four starters as tiles. A first run shows a three-step checklist (sign in, pick a project folder, give Graff a small task) instead of the old canvas, and Skip still starts outside a project.
- New installs show less by default: tool steps fold into one line and sidebar rows hide branch names. Both are one toggle away, and existing settings don't change.
- On iPhone, Home has the same composer and starter tiles and the same Needs you / Today / Earlier grouping. On iPhone Duo half open, the lower half is four big buttons: Stop, Show changes, Terminal and Talk to Graff.

## See what a turn changed

- After a turn edits files, an "N files changed" card above the composer opens the Changes pane, which now has **Keep changes** and **Undo all changes**. Undo reverts every uncommitted file in the checkout, after the usual confirmation.
- While a command runs, a small pill says what is running, with Stop, and the work pane opens on the Changes tab by itself. It closes again afterwards if nothing changed; a pane you opened yourself stays open.
- With ⌘D split panes, the other panes are no longer dimmed. The pane you're typing in has an accent line and a "Typing here" tag.

## Smoother while agents work

- The sidebar no longer redraws every chat each time a running chat's spinner moves, which made typing and scrolling stutter while agents ran. It also builds only the chats near the screen, so scrolling a long list stays smooth.

## Quieter updates

- Harness downloads and installs updates without showing anything until it's done. If you're in another app when it restarts, it restarts in the background without a countdown. The update button only appears when something needs you: an update that failed, updates set to manual, or one you chose to install later.

## Cloud sandboxes and models

- With the sidebar collapsed, a running cloud sandbox shows as a cloud button with a live dot in the titlebar, instead of a card floating over the tab title. Its menu shows the cost, with Settings and Turn off. With the sidebar open, the strip is one line.
- The model card has a **Context** row with the model's context window, and the footer reads it the same way, such as "1M context" instead of "1000k context".
- In Settings → Accounts, Claude Agent comes first among graff's providers, with its own logo, and says it uses your Claude Code login and your Claude plan.

## Fixes

- An image you attach is no longer shown a second time under the reply when the agent opens it.
