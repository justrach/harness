# Harness v0.2.100-beta.3

Beta. Developer ID signed and notarized. Everything in
[v0.2.100-beta.2](v0.2.100-beta.2.md) is included. This is a prerelease for
testing: stable installs and the auto-updater do not see it.

## On the phone

- **Swipe between sessions.** Swipe the open session's header, or the switcher
  pill, to move to the next or previous session you are juggling. It pages
  through what is running or waiting on you plus the session you are in; Back
  still returns Home in one step. A small position marker next to the title
  shows where you are.
- **Now strip.** Home shows a row of swipeable cards for sessions that are
  running or need you, with a live preview of each, above the history.
- **Newest first.** Home opens on Time (newest prompt first) every launch
  instead of staying on a saved Project grouping.
- **Model picker offline.** The picker keeps the agents it last saw on your
  computer while it is unreachable, instead of falling back to Claude Code and
  Codex only, and reloads when your computer comes back.

## Also in this beta

- Import conversations from Claude Code, Codex and graff.
- The Codex terminal client.
- Everything that has landed on `main` since beta 2.

## Updating

This beta moves to the next stable release on its own. To move to a newer
beta, install its prerelease.
