# Harness v0.2.105

Stable patch release for macOS, Windows and Linux. Includes the changes in
[v0.2.104](v0.2.104.md).

## Reconnect ChatGPT

- When ChatGPT asks you to sign in again, the chat now always offers
  **Reconnect ChatGPT**. Before, if the agent exited right after reporting the
  expired sign-in, the chat could end with "exited unexpectedly" and no way to
  reconnect from there.
- Buttons that start or retry the new ChatGPT plan sign-in now read
  **Continue with ChatGPT**, in Settings → Accounts, on the reconnect card
  and on iPhone. The legacy Codex and other sign-ins are unchanged.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
