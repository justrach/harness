# Harness v0.2.147

Desktop update for macOS, Windows and Linux.

## See what's filling the context window

- Hovering the usage ring in the composer footer now shows a bar of what fills the context window: chat history, recent chat, files, commands, search and web, other tools, and system. A legend gives each part's tokens, and a line says how much room is left.
- When the agent compacts, the card shows it happening. A summary the agent wrote shows as "Chat summary"; a compaction the provider keeps sealed (as Codex's does) shows as a locked "Compacted context" block, with its size only.
- A strip under the bar traces the context over the session, with each compaction marked.

## Follow a running turn's steps and subagents

- While the agent works, a chip left of the usage ring shows its to-do steps as dots, or how many subagents are running.
- Hovering it opens a card with the steps so far, what the current step is doing (running, writing, reading, searching), any question waiting for you, the subagents with their latest output, and the tools used this turn.

## Markdown links with spaces open

- A link to a file whose path has spaces or other escaped characters, such as `Demo%20Folder/Guide.md`, now opens the file instead of reporting "file not found".
