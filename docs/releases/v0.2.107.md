# Harness v0.2.107

Stable patch release for macOS, Windows and Linux.

## Pull request badge polling

- Harness no longer launches a continuous stream of `git` and `gh` processes
  while conversations show pull request badges. Previously, every watched
  conversation inspected its checkout on its own short timer and queried
  GitHub on its own, so the background process count grew with the number of
  conversations and kept running for as long as the app was open.
- Checkout inspection is now shared by every conversation in the same
  checkout and refreshed at most once a minute. Badge lookups go through a
  single queue, so at most one of these background processes runs at a time.
- Badges refresh every few minutes for open pull requests and branches
  without one, and less often for merged or closed pull requests.

## ChatGPT sign-in status

- The ChatGPT (graff) row in Settings → Accounts now shows "Signed in" after a
  successful ChatGPT sign-in. Previously the row never reflected the saved
  credential, so a completed sign-in looked like nothing had happened.
  "Continue with ChatGPT" stays available to sign in again.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
