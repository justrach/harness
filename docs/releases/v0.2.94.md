# Harness v0.2.94

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.93](v0.2.93.md) is included.

## Updates

- Settings → Devices shows the Harness version and a Check for updates button,
  so a new release shows up right away instead of on the next 6-hourly check.
  When one is out, the button becomes Update to vX.

## Keyboard

- ⌘W no longer closes Harness. It closes the right-pane tab, then the split
  pane, then the chat tab, then leaves the chat for a new session, and does
  nothing on an empty new session, so running agents are never stopped by it.
  Close the window with ⌘⇧W (both are in the Window menu).

## Agent questions

- The transcript shows the question the agent asked, with "Waiting for you"
  until it is answered, instead of a generic "Agent question" row.
- Submit and Next send what you typed. They used to send a blank answer the
  agent read as a dismissal, and an unanswered question no longer submits.
- Questions wrap in narrow panes, long answers grow then scroll, and the
  thinking indicator hides while a question waits for you.

## Sidebar and tabs

- Session rows keep their timestamps instead of split-pane badges, with a
  10px gap before the timestamp in compact mode.
- Archive sessions when closing tabs also guards pending sends and sessions
  open in another window, and handles quick successive closes.
