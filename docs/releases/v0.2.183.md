# Harness v0.2.183

## Highlights

- **Composer scrollbar suppression (`apps/nano/src/view_composer.zig`, `apps/nano/lean-proofs/Nano/FrameSchedule.lean`, `apps/nano/src/motion_rules.zig`)**:
  - Disabled the internal `nanoui` scrollbar thumb inside the rounded composer text field (`.scrollbar = false`), eliminating the persistent floating vertical bar inside the composer pill (`composer_scrollbar_always_hidden`).
- **Clickable/draggable text selection & `Cmd+C` copy (`#717`, `#745`) (`apps/nano/src/view.zig`, `apps/nano/src/view_markdown.zig`, `apps/nano/src/view_transcript.zig`, `apps/nano/src/view_tool_tree.zig`, `apps/nano/src/view_working.zig`, `apps/nano/src/view_actions.zig`, `apps/nano/src/view_question.zig`)**:
  - Enabled `.selectable = true` across transcript messages, markdown paragraphs/headings/lists/tables/blockquotes/code/math, tool call rows & outputs, working strip status, action dock/toolbar labels, and question cards.
  - Added `settleSelectionPreTree` and `settleSelectionPostTree` to snap drag endpoints across inter-word whitespace (`snap_whitespace_preserves_order`, `snap_whitespace_lands_on_word`), enforce mutual exclusion between rendered-text selection and `TextField` selection (`step_selection_owner_no_dual_selection`), clear stale selection on chat/overlay transitions (`selection_cleared_on_chat_switch`, `selection_cleared_on_overlay_open`), and copy rendered selection on `Cmd+C` even while the composer has an unselected caret (`rendered_selection_copied_over_unselected_composer`).
- **OS browser link opening & inline-code / tool-output URLs (`#348`) (`apps/nano/src/app_browser.zig`, `apps/nano/src/browser_url.zig`, `apps/nano/src/markdown.zig`, `apps/nano/src/view_tool_tree.zig`)**:
  - Clicking external links in live desktop windows now opens them directly in the OS browser via `nanoui.shell.openUrl` while preserving the in-app `Browser` surface in headless `ui.Tester` tests.
  - Backticked inline-code spans containing a URL and tool outputs containing an `http://` or `https://` URL are now clickable links.
- **Sidebar open-workspace visibility (`apps/nano/src/view_sidebar.zig`, `apps/nano/src/tests_ui_tab_strip.zig`)**:
  - Removed the single-chat workspace exclusion in `openWorkspaces` so every open workspace tab appears in the sidebar when multiple workspaces are open (`single_chat_workspace_visible_when_multiple_open`).
- **Desktop & TUI bug fixes (`#788`, `#789`, `#790`, `#792`, `#793`, `#794`, `#795`, `#797`, `#799`)**:
  - `#788`, `#789`, `#790`: Removed failed tool pill/patterned wash, legacy `All sessions` / `Task view` controls, and non-composer attachment drop targets (`apps/nano/src/view_attachment_drop.zig`, `apps/nano/src/view_tool_rows.zig`, `apps/nano/src/tests_desktop_regressions.zig`).
  - `#792`: `Cmd+Shift+P` now toggles the project picker open and closed (`apps/nano/src/view.zig`, `apps/nano/src/view_tab_strip.zig`).
  - `#793`: `Cmd+/` toggles the model picker open and closed (`apps/nano/src/app.zig`), and `Cmd+Shift+T` reopens closed tabs from a bounded LIFO stack (`apps/nano/src/tabs.zig`, `apps/nano/src/app_tab_layout.zig`).
  - `#794`: Distinct sidebar tooltips (`"Search sessions"` vs `"New workspace"`) (`apps/nano/src/view_sidebar.zig`).
  - `#795`: Currency-safe `$` inline math delimiter parsing (`$100 ... $200` remains plain text, `currency_range_not_inline_math`) and Unicode math symbol/fraction/root/script formatting (`apps/nano/src/markdown.zig`).
  - `#797`: Startup `restoreTabs` respects dirty boot-canvas drafts (`dirty_boot_canvas_fences_tab_restore`) and skips archived chats (`archived_chat_never_restored`) (`apps/nano/src/app.zig`).
  - `#799`: TUI bridge `thread/list` (`session/list`) supports `cwd` (string or array), `searchTerm`, `sortKey`, `sortDirection`, `cursor`, `limit`, and `nextCursor` (`tui/bridge/src/engine_threads.rs`).
