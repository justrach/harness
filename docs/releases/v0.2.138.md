# Harness v0.2.138

Desktop release for macOS, Windows and Linux: a new session can be a plain
chat on the hosted Auto models, agents can use your own browser through
browse, and the phone can open and drive a Mac's iOS Simulators.

## Chat mode

- The new-session canvas has a **Chat / Code** switch. A chat has no project,
  checkout or branch; it runs graff from your home folder and asks "What's on
  your mind?".
- Its model menu offers only the hosted Auto tiers: **Auto (low)**, **Auto
  (high)** and **Auto (smart)**. A chat starts on Auto (low) and remembers its
  own last pick without changing your coding defaults. Auto (smart) notes that
  it may incur API costs.
- The mode is stored on the chat, so an existing chat keeps it. Older apps
  ignore it.
- If the Auto tiers aren't available (signed out, offline, or an older
  gateway), the switch stays on Code and says why, and a chat-mode draft holds
  its send instead of falling back to another model.
- On iOS and Android, **New chat** in the + menu starts the same kind of
  chat after you pick the computer that hosts it.

## browse

- Settings → Accounts → **browse** (macOS) pairs Harness with the browse app:
  both show the same six digits, you confirm in browse and choose what agents
  may do. Harness's key stays in your login Keychain.
- Each agent run that takes HTTP MCP servers gets a `browse` server through a
  local relay with a per-run token. Every request is signed, browse's answers
  are verified against its pinned key, and the run's pages close when it
  ends. Refusals tell the agent what's missing (a scope, tabs you declined, a
  stale clock), and revoking Harness in browse forgets the pairing.

## Simulators

- On iOS, Settings → **Simulators** lists a Mac's iOS Simulators. Open one to
  watch it live and use it from the phone: taps, swipes, typing, and the
  Home, Lock and volume buttons. A simulator that's off starts when opened;
  swipe to shut one down.
- Nothing is installed until you tap **Set up**, which installs a pinned
  streaming helper on the Mac with its install scripts disabled. The helper
  serves only the screen and input for one simulator, on loopback, behind a
  token that changes every run, and stops with Harness or after a minute
  nobody is watching.
- Only your own devices can reach it. Video is capped at 960 px and 20 fps,
  and the phone asks for a lower frame rate on cellular or Low Data Mode.
  Simulators are macOS only.

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
