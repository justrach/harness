# Harness v0.2.171

Tool activity in chat is easier to follow: tool calls animate as they run, and a Tool Access Map shows which tools the agent can use. Built on v0.2.170 (panels, recoverable chats, no branch prompts). (#769)

## Desktop

- Collapsed tool groups use compact one-line rows for Search, Read, Edit, Run and the rest. Active rows show a gray pill, icon, verb, a scrambling path, and a timer; finished rows settle the path and show a short summary (matches, files, or +N −N). Failures fade in red from the right with a red "failed" pill; passes use green. The header ends like "7 tool calls, 1 failed" with aggregate file diffs when edits landed. All of this is driven by the turn's real tool events.
- A Tool access control under a tool group opens a right-pane map for that chat. Tabs are the chat's real agent and any subagents it spawned — not demo personas. The graph places input tools on the left, the selected agent in the center, and output tools on the right, with blue links to tools in use and unused tools faded. Click a tool for history, INPUT / OUTPUT, Edit input and Replay (Replay spins a history row, updates the running badge, then shows a success payload). Light and dark follow the current theme.
