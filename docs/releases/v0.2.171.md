# Harness v0.2.171

Tool activity in chat is easier to follow: tool calls animate as they run, and a Tool Access Map shows which tools the agent can use. Split panels now share one bar across the top. Built on v0.2.170 (panels, recoverable chats, no branch prompts). (#769)

## Desktop

- Every row in an open tool group now shows how it went. A running row sits in a gray pill with a scrambling path and a timer; a finished row settles, with a short result at its right end when there is one to give (matches, files, or +N −N). A failure has a red fade at its right end and a red "failed" pill, and a test run says how many failed or passed, in green when they all did. A row that can open shows a chevron at its right end, and its input and output open under it. Changed files are listed under the rows once the turn is done. All of this is driven by the turn's real tool events.
- A Tool access control under a tool group opens a right-pane map for that chat. Tabs are the chat's real agent and any subagents it spawned — not demo personas. The graph places input tools on the left, the selected agent in the center, and output tools on the right, with blue links to tools in use and unused tools faded. Click a tool for history, INPUT / OUTPUT, Edit input and Replay (Replay spins a history row, updates the running badge, then shows a success payload). Light and dark follow the current theme.
- With one panel, tabs stay where they were. Once the window splits, one bar across the top replaces every panel's tab row, with a slot above each panel showing its title, its computer and its folder. A slot's + adds a tab inside that panel, and its menu holds the panel's other tabs and its actions. Dragging a slot onto another moves its tab there. An amber or red dot appears only when a tab has a question or an error.
- A new chat's slot can change its folder from the top bar. Each new chat keeps its own folder, and the sidebar stays as it is. A chat that has started only shows its folder.
- New shortcuts for split panels: ⌘⌥1 to ⌘⌥6 reach a slot (Alt+Shift+1 to 6 on Windows and Linux), and ⌘⇧J (Ctrl+Shift+J) goes to the next tab asking for something.
- On a Mac, while a chat is running, ⌘Q has to be held for a moment to quit, so a slip next to ⌘W can't stop it. A tap says why nothing happened. With nothing running, and from the menu or the Dock, quitting works as before.
- An updated app now warns in the sidebar when it has connected to an engine still running an older version, and says how to restart it.
- Scrolling a transcript no longer redraws the sidebar and composer on every wheel tick, or the other panels' transcripts when split.
- A long tool title stays on one line in a narrow panel instead of losing its last word, and a panel's controls appear only while its header is hovered.
