# Harness v0.2.89

Pairs with Codegraff `graff` v0.0.302.5. Developer ID signed, notarized and stapled.
Everything in [v0.2.88](v0.2.88.md) is included.

## Getting started

- A first launch no longer stops at "Add a project". It says what Harness does and
  offers starters that need no repo: Build something new, Research a topic, Plan a
  launch, or Work on existing code. Each fills in a ready-to-finish prompt.
- New sessions show which project they start in ("New session in codedb"); click it
  to switch. Starter chips sit under the empty composer.

## Tabs and splits

- ⌘T opens a new tab; each tab keeps its own split layout. ⌘⇧] / ⌘⇧[ switch tabs,
  and ⌘W on a tab's last pane closes the tab.
- ⌘D opens the new pane in a tab when another side-by-side pane would be too narrow
  to read.
- ⌘K lists open panes first and jumps to the one you pick, across tabs.
- The machine and project pickers no longer spill out of narrow panes.

## Subagents

- Graff's background agents read as subagents: "Waiting on <task>" links to the
  subagent's live transcript instead of a bare `agent_output` tool row. Message,
  resume and wait rows from Codex and Graff are named too.

## Screen Recording

- When macOS blocks an agent's screenshot, Harness says so and offers to request
  Screen Recording access, then restart. Settings → Agents shows the status.
- The development build ("Harness Dev") has its own bundle id, so its permissions
  no longer collide with the installed app's.
