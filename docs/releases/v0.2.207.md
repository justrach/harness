# Harness v0.2.207

## macOS Compatibility

- **macOS 12.0+ deployment target:** Pins Zig builds (`apps/nano/build.zig` and `scripts/package-macos.sh`) to `macos.12.0` while keeping Rust's `11.0` default deployment target intact, and enforces an `otool -l` `LC_BUILD_VERSION` `minos` gate so bundles built on newer macOS hosts remain runnable on macOS 12.0 and all newer releases (including macOS 15, 26, and 27+).

## Auto-Updater Handoff to NanoHarness

- **NanoHarness release feed migration:** Points desktop macOS apps, managed CLI installs, Windows portable installs (`harness-update.json` migration + `harness-engine.exe` extraction), and Nano release polling at `justrach/nanoharness` so future automatic updates transition cleanly to NanoHarness releases.

## Desktop Markdown & Sidebar

- **Escaped bars in Markdown table cells (`#889`):** Preserves escaped vertical bars (`\|`) inside Markdown table cells, LaTeX math spans (`$\|x\|$`), and inline code spans instead of splitting columns.
- **Auto-hide `Cmd+B` sidebar scrollbars (`#845`):** Hides overflowing sidebar scroll rails after three idle seconds across Developer and Zen modes, ignoring stationary hover while keeping active thumb drags visible.

## Agent Engine & MCP Parity

- **Capability error classification (`justrach/codegraff#1907`):** Avoids misclassifying provider `unsupported_capability` errors as `Signed out` across shared desktop and mobile run-error parity rules.
- **MCP `readOnlyHint` tool annotations (`justrach/codegraff#1908`):** Marks the 11 read-only Harness MCP inspection tools (`whoami`, `list_devices`, `list_projects`, `list_harnesses`, `list_models`, `list_chats`, `get_chat`, `read_chat`, `list_rooms`, `room_inbox`, `list_bots`) with `annotations.readOnlyHint: true`.
