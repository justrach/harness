# Harness v0.2.179

`harness-nano` is now the desktop app across macOS, Windows, and Linux, replacing the Rust GPUI client (`crates/ui` and its vendored `zui` / `gpui-component` forks), with 120Hz word-by-word streaming dissolve veils, live inline-Markdown balancing, background desktop self-updates, and `ReleaseSafe` runtime checks. Built on v0.2.178.

## Desktop (`harness-nano`)

- **Model picker context badge fix, `<- Models` crash fix, and Zeron-style reasoning effort animations (`apps/nano/src/view_picker.zig`, `apps/nano/src/model_picker.zig`, `apps/nano/src/view_composer.zig`, `apps/nano/src/view_kit.zig`)**:
  - Fixed the `?` replacement glyph on model row context window badges (`500k`, `200k`, `1M`) by allocating formatted badge text in the per-frame arena (`c.alloc()`) instead of a stack-local buffer (`var ctx_buf: [24]u8`).
  - Fixed a panic (`attempt to use null value` in `view_picker.zig:slider`) when clicking `<- Models` on the Reasoning page by removing all `p.stage.?` force-unwraps after `back(c, a)` clears `p.stage = null` mid-frame.
  - Set `stage_height = 293` to match the Reasoning page's natural content height so opening the Reasoning stage transitions smoothly without a 2-frame vertical bounce.
  - Ported Zeron's effort animations (`crates/ui/src/pickers/compact.rs` and `crates/ui/src/roll_text.rs`):
    - Continuous `drag_fraction` pointer tracking on the reasoning effort slider that seeds `ScalarTransition` (`from = fraction, to = fraction`) while dragging and glides smoothly along the `RESIZE` curve (`cubic-bezier(0, 0, 0.58, 1)`, 200ms) from the exact release pointer to the snapped stop;
    - Animated press elevation shadow (`press_anim`) and breathing accent halo + flowing light-wave shimmer across the filled track on deeper reasoning levels;
    - Scritto-style per-grapheme rolling text (`kit.rollText`, `sharedEnds`, 550ms `ease_out_quint` with 30% left-to-right stagger) and 200ms width glide (`chip_width`) on the Reasoning page effort badge and the composer's model/effort chip.
- **Lean 4-verified 120Hz `⌘B` sidebar tween isolation (`apps/nano/lean-proofs/Nano/Tween.lean`, `apps/nano/src/motion_rules.zig`, `apps/nano/src/view_transcript.zig`)**:
  - Formally proved in Lean 4 (`cmd_b_culling_invariant_of_scroll_resize_stream`, `cmd_b_column_width_invariant`, `cmd_b_shift_budget_preserved`) and wired into `view_transcript.zig` that while `sidebarTweening` is active, `tweenColumnWidth` locks to the settled post-tween target width on frame 1 so `retain.shift` translates existing transcript glyph quads in `O(1)` GPU time without per-frame text re-wrapping, and `shouldCullOffscreen` stays active regardless of scroll, resize, or streaming state.
- **Lean 4-verified `⌘W` open file / workbench tab close priority (`apps/nano/lean-proofs/Nano/FrameSchedule.lean`, `apps/nano/src/motion_rules.zig`, `apps/nano/src/app_files.zig`, `apps/nano/src/app_panels.zig`)**:
  - Updated `decideCloseTarget` (and proved `cmd_w_visible_host_closes_before_chat` in Lean 4) so pressing `⌘W` while a file or workbench host tab is open and visible closes that open file/workbench tab first before closing any chat tab or split pane.
- **120Hz `⌘+` (`⌘=`), `⌘-`, and `⌘0` interface zoom (`apps/nano/src/settings.zig`, `apps/nano/src/app.zig`, `apps/nano/src/view.zig`, `apps/nano/src/native_menu.zig`, `apps/nano/src/shortcuts.zig`)**:
  - Added `⌘=` / `⌘+` (`Bigger Text`), `⌘-` (`Smaller Text`), and `⌘0` (`Actual Size`) keyboard shortcuts and native `View` menu accelerators that step `uiFontSize` through `12, 13, 14, 15, 16, 18, 20 px` (`c.setZoom(uiFontSize / 16.0)`) and reflow at 120Hz.
- **Context usage hover card linear-ease-out hero jump (`apps/nano/src/view_context.zig`)**:
  - Clamped the Context usage hover card strictly above the `5%` context ring pill (`anchor.y - h - 6`) so it never overlaps the footer pill, and added a 120Hz linear-ease-out upward hero jump (`1 - (1 - t)^3` over `140ms`) from the pill into the resting card position.
- **Readable MCP & tool call titles (`apps/nano/src/view_tool_tree.zig`)**:
  - Removed `rules.scramble` from tool names and paths in `view_tool_tree.zig` and marked tool call parts with recorded output or errors as resolved so completed MCP tool calls (`mcp__deepwiki__ask_wiki_question`) never render garbled placeholder text.
- **True circular composer Send / Voice / Jump buttons (`apps/nano/src/view_composer.zig`, `apps/nano/src/view_kit.zig`, `apps/nano/src/view_picker.zig`)**:
  - Added `.circular()` (`corner_circular = true`) to the composer's `28×28` Send/Stop button, Voice button, Jump-to-bottom pill, reasoning slider thumb, and circular `kit.iconButton` controls so they rasterize with true circular SDF corners instead of faceted squircles.
- **Accessible Settings `< Back` navigation (`apps/nano/src/view_settings.zig`)**:
  - Added a prominent `Back` pill button (`#settings-top-back`) at the top of the Settings sidebar directly beneath the window traffic lights and upgraded the bottom `Back` button (`#settings-back`) to a full-width bordered pill with an `esc` keycap badge.

## iOS

- **Workspace & Settings redesign**: Updated `WorkspaceView`, `SettingsView`, `ChatRowView`, and `ChatScreen` with smooth spring transitions, refined session canvas headers, and clean grouped settings rows.
