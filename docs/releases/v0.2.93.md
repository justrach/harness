# Harness v0.2.93

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.92](v0.2.92.md) is included.

## Tabs and splits

- Drag a chat tab onto another to move it. Tabs are saved and come back on launch.
- A tab's pane cards sit right under that tab.
- A new ⌘D pane or ⌘T tab starts with an empty composer instead of copying the
  prompt you were still writing. Each pane and tab keeps its own draft.
- ⌘D starts the new session in the current session's folder, even when the
  folder picker points somewhere else.
- Split panes use narrower side margins: 48px in wide panes, down to 12px in
  narrow ones.
- Right-pane tabs can be dragged to any position; the strip scrolls while you
  hold a tab near either end.
- New setting, off by default: Settings → Archived → Archive sessions when
  closing tabs. Sessions that are still running, or open elsewhere, are kept.

## Sessions

- Sidebar session rows no longer show pull-request badges. The command palette
  still shows them.
- Files you paste or attach while answering an agent's question go with the
  answer.
- When graff compacts its context, the transcript shows a Compact context row
  with the summary.
- The working indicator stays up until the session list catches up after a send.

## Terminal and platform

- `harness` and `codegraff` in the terminal open the installed app, never a
  development build, and replace the old Codegraff launcher script.
- Agent launches retry when Linux reports the executable as busy.
