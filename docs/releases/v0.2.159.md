# Harness v0.2.159

A new setting for macOS, and a new iOS build on TestFlight.

## Keep this Mac awake while agents work

- Settings → Agents has a new switch, off by default. While it is on and any chat is working, the Mac won't go to sleep; once every chat is done it can sleep again. A chat waiting on your answer doesn't count. The display can still turn off, and closing a laptop's lid still puts it to sleep.

## iOS

- The app no longer crashes when a transcript gets shorter while it is still laying out.
- Editing a queued message keeps Attach and paste, so you can add images to it in the composer.
- The Stacked phone split is gone; Split view offers Off, Auto and Side by side. A saved Stacked choice becomes Auto.
