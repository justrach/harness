# Harness v0.2.85

Harness is now the desktop GUI for Codegraff, maintained and released from its
own repository. This release pairs the Harness app with Codegraff `graff`
v0.0.302.5. The macOS download is a signed and notarized `Harness.app` in a
drag-to-Applications DMG; the app's own update feed follows stable Harness
releases. Beta builds produced from Codegraff release-branch pushes remain
separate intermediate artifacts and do not enter the stable updater feed.

## Graff sessions in the desktop app

- Graff is available as the default coding agent through its ACP interface.
  The packaged macOS app carries the exact `graff` executable used for this
  release. On first launch, Harness places a managed copy in its application
  data directory and makes `graff` available to new terminal sessions without
  requiring a second download. Existing user-owned CLI files are preserved.
- New Graff sessions start in the workspace selected in the GUI. Session
  restoration checks workspace identity, including equivalent directory
  paths, before loading prior context; a session from another workspace is
  not silently reused.
- The model picker reads reachable Graff routes and keeps the selected
  provider route with saved model choices. A resumed session verifies that
  route before sending its next prompt, so a stale picker value cannot quietly
  send a request through a different route.
- Reasoning choices advertised by the installed Graff binary now appear in
  the desktop picker. The selected level is carried into the ACP session and
  restored with it. Optional controls distinguish an explicit **Off** choice
  from a missing value, while older Graff binaries receive a conservative
  picker rather than unsupported choices.

## Desktop experience

- Chats can use split panes. The app restores its previous session on launch
  and supports Codegraff sign-in from the desktop flow.
- Rendering and terminal output handling have been tightened for long,
  active sessions. The work includes coalesced PTY reads and narrower GPU
  diagnostics; it does not change the engine protocol used by the GUI.
- Desktop guidance and error text now use the Harness name and CLI commands.
  The macOS installer has new Codegraff artwork and a clear
  drag-to-Applications layout.

## Distribution and updates

- Stable macOS releases require Developer ID signing, hardened runtime,
  notarization, and stapled tickets for both the app and DMG. The app update
  tarball contains the stapled app. The release includes a versioned DMG and
  the stable `Harness-macos-arm64.dmg` download alias.
- The installed macOS app checks Harness's stable release manifest, verifies
  the app tarball checksum, and stages an update for a user-controlled restart.
  Source builds remain under the developer's control.
- Codegraff's current release branch can trigger a Harness beta GUI build;
  the Harness workflow also checks for new beta and stable Codegraff releases
  on a schedule. Those builds record the included revisions and recheck the
  source release before retaining an intermediate artifact. A signed Harness
  stable release is still a deliberate release step.
- Linux headless and Windows portable archives remain available as separate
  assets. The macOS GUI download currently targets Apple silicon.

## Licensing and migration

Harness contributions are licensed under AGPL-3.0-only, with prior Zeron and
other third-party notices retained in the repository and packaged app. Harness
has its own macOS app identity and data directory, so it can be installed
alongside an earlier Codegraff desktop app. Installing Harness does not delete
that app or its data.

Download the signed macOS installer from this release and drag **Harness** to
**Applications**. Open Harness once to set up its bundled Graff CLI, then
select a workspace and start or resume a chat.
