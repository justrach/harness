# Harness v0.2.198

## Desktop

- **GitHub stays beside its chat.** Cmd+R opens the GitHub pane next to the invoking conversation, with an attached tab and curved shoulders. Useful minimum widths and a compact focus-mode fallback keep repository content and pagination accessible instead of squeezing or clipping them.
- **Smooth image inspection.** Scroll or pinch to zoom toward the pointer in chat and GitHub image previews. Zoom buttons and Fit animate smoothly, dragging stays direct, and Reduced Motion disables the transition. Keyboard focus stays inside the preview and returns to the opening image when it closes.
- **More consistent keyboard controls.** Shared toolbar, sidebar and composer controls, menus, GitHub cards and file disclosures support keyboard activation and visible keyboard focus. GitHub tabs and filters support arrow keys and Home/End without fetching until the selection is activated.
- **The composer no longer covers queued messages.** The queue, growing input and Scroll to bottom control occupy separate space, including with attachments and multiline drafts. Long queues keep their last row reachable.
- **Open generated media from replies.** Local file links in the owning conversation can open supported videos, images and PDFs through the conversation's host. Reads retain canonical-path checks, size limits and content validation; unsupported files show an explanation rather than silently doing nothing.
- **Clearer agent sign-in startup.** Antigravity uses its own account, independent of Harness sign-in. The pending label now describes sign-in startup, and canceling an attempt before its startup response arrives also cancels that late response without replacing a newer attempt.

## Verification and scope

The native frontend suite passed 1,126 tests with 3 skipped. Focused portable artifact-link tests passed 27 tests, host attachment-reader tests passed 8 tests, and the ReleaseSafe frontend build passed. Synthetic regressions cover pane ownership and sizing, image zoom and focus, keyboard controls, queue/composer separation, sign-in cancellation and generated-artifact activation.

Local artifact paths currently support POSIX-style paths; unsupported Windows path forms fail closed. OS media-player handoff and screen-reader behavior were not exercised against live desktop applications. The sign-in lifecycle fix does not claim to diagnose an external agent's authentication service. Unrelated LSP and native-extension panel work remains separate from this release.
