# Harness v0.2.103

Stable patch release for macOS, Windows and Linux. Includes the changes in
[v0.2.102](v0.2.102.md).

## Agents

- Choosing a model that pairs a lead and a worker model, each with its own
  thinking level, no longer times out waiting for the selection. Harness keeps
  the whole pairing, confirms the thinking level and speed before sending the
  prompt, and other agent options can no longer change the speed you picked.

## Windows

- The minimize, maximize and close buttons show their icons on every
  version of Windows. On PCs without the Windows 11 icon font they appeared
  as empty boxes.
- Split chat panes can be closed on Windows and Linux. Press Ctrl+Shift+W to
  close the pane you are in, or click the close button on another pane's
  title; closing the other panes takes you back to one column.

## Shortcuts

- `/help` opens Settings → Shortcuts, which now also lists the shortcuts for
  splitting, moving between, resizing, zooming and closing panes, chat tabs
  and the message box, with each computer's own keys.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
