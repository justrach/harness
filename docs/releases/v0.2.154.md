# Harness v0.2.154

Desktop update for macOS, Windows and Linux, and a new iOS build on TestFlight.

## Choose how much agents may do without asking

- Each computer now keeps a default autonomy for its agents: **Read only** (read and search; anything else is asked first), **Workspace** (edit files in the project; ask before anything outside it) or **Full access** (no questions, how Harness has always run).
- Full access stays the default, so nothing changes until you pick a level. Pick it from the iPhone app, in the first-run setup or in Settings → Agents → Autonomy.
- With Read only or Workspace, Claude Code, Codex, graff and other ACP agents ask before going further, and the question shows up in the chat as Yes or No.
- A new level applies from your next message; a chat that is mid-turn finishes its turn first.

## Pick the reasoning level for every agent

- In the model picker, choosing a Claude Code, Codex or other agent's model opens the level slider again. Before, only graff's models had one, and the others said they had no adjustable reasoning level.

## Web addresses in inline code are clickable

- An inline code span that holds only a web address, such as `https://example.com/docs`, opens like any other link, from the mouse or the keyboard, and keeps its code styling. Commands and other code stay plain text. Thanks to yxlyx.

## Selecting text in the transcript

- Clicks and drags next to a collapsed prompt land on the text you can see, instead of the prompt's hidden lines.
- A right-click during a drag no longer ends the selection.
- Double-click selects whole words, accents and emoji included.
- A selection across table columns, or one whose start scrolls out of view in a long chat, keeps its start. Thanks to yxlyx.

## iOS

- **First-run setup.** After a fresh sign-in, four short steps set real defaults: the agent that starts your sessions (graff first), how hard it thinks, how much it may do without asking, and whether to notify you when it needs you. Skip leaves everything as it was, and Settings → Replay setup runs it again.
- **No notification prompt at launch.** iOS asks only once you say yes in setup or Settings.
- **The desktop's look in a session.** The reasoning level is a slider from Faster to Deeper. A context ring sits at the end of the status strip, and tapping it opens the context card. An agent work chip beside the running indicator opens the turn's steps, subagents and tools. Working spinners use your theme's accent.
- **iPhone Duo, folded.** Tool activity reads as one line of chips, edits get a summary card with their files and line counts, a running turn shows as a small status pill (Stop sits behind it, never next to Send), the title wraps to two lines, and swiping from the left edge goes back.
- **iPhone Duo, lying flat.** The session list sits in a column beside the chat. Opening a diff swaps the list for Inspect, with Diff, Terminal and Files.
- **iPhone Duo, half open.** The chat sits above the hinge and Inspect below it; while you type, a one-line status strip sits above the composer.
- **On a Duo the composer is one line** while you type, with its chips folded into one token that opens the model picker.
- **Duo fixes.** The header no longer hides under the back button in laptop pose, the open session keeps its height when the keyboard comes up below the fold, the floating search no longer covers a row, and the Sessions title no longer blurs under the toolbar.
- Inspect fills in from the computer's diffs and command output as those reach the phone; until then live sessions show the summary and an empty pane.
- The autonomy setting needs Harness 0.2.154 on the computer. An older version shows "update Harness" instead.
