# Harness v0.2.174

Chats follow Graff when it switches worktrees mid-run, macOS computer use installs even when Graff is already up to date, and sign-in stays kept across sleep and dropped token-refresh replies. Built on v0.2.173.

## Desktop

- Switching checkouts or worktrees mid-turn in Graff updates the chat's active folder and branch immediately, so `show_image` and workspace panels follow the newly selected tree without restarting the session.
- On macOS, managed Graff updates and app startup install `nanocua.app` into the user `Applications` folder even when the managed `graff` binary is already on the latest version.
- An unanswered account token refresh now stays eligible for replay across the full 7-day server grace window using wall-clock time as well as monotonic time, so sleeping a Mac or losing a refresh reply mid-flight does not sign you out.
