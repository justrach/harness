# Harness v0.2.86

Pairs the Harness desktop app with Codegraff `graff` v0.0.302.5 (stable). Harness
keeps Cargo's three-part semver, tagged `v<version>` like Codegraff's releases, and
names the Codegraff release it bundles in each release's notes. The macOS download
is a Developer ID signed, notarized and stapled `Harness.app`. Everything in
[v0.2.85](v0.2.85.md) is included.

## Graff worktrees, Graff's way

- A Graff chat started in a new worktree now runs in **Graff's own** named worktree
  (`graff acp -w harness-<chat>` → `.graff/worktrees/<name>` on `worktree-<name>`)
  instead of a Harness-made `harness/<name>` tree. Graff runs the checkout's
  `.graff/workspace.toml` setup and never reaps named trees between turns.
- Harness follows the tree Graff reports: later turns, session restore, and the
  diff and files panels all work inside it.
- The composer footer shows a **Graff worktree** card with **Merge back**
  (squash-land onto the main checkout), **Archive** and **Remove**, plus
  **Discard anyway** when Graff reports work that exists nowhere else. Results are
  Graff's own words.

## More agents

- **Exo** joins as an ACP agent (off by default; enable it in Settings → Agents).
- Antigravity 1.2.1 (about half the cold-start time and memory), Grok 1.0.41 with
  sign-in errors surfaced, Cursor SDK 1.0.32.

## Split panes and scrolling

- Up to 8 chat panes; past four the column is shared evenly. A split that can't
  happen no longer drops the whole layout.
- Sending (including steering mid-reply) no longer jumps a long chat to its top.

## Faster, leaner engine

- Watches for closed terminals, switched workspaces, deselected chats and MCP
  reads end immediately instead of lingering until their next update.
- Boot no longer opens every past chat; chat sync connections and dials share a
  budget, with the focused chat kept connected under pressure.
- Faster run-journal scans (~100× on stale-session checks), incremental transcript
  publication (~5×), memoized tool diffs (~14×), cancellable highlighting, and a
  cheaper sidebar tick.
- A slow or stuck stream no longer stalls the app's connection to its engine.
