# Harness v0.2.161

Fixes for desktop and iOS.

## Commands work after a branch change

- If a chat's checkout changed branch, a message waits behind a "Branch changed" question. Answering "Continue on …" sent a held `/compact` (or any other `/command`) with a note in front of it, so the agent read it as plain text and nothing ran. A held command now goes as typed.

## iOS

- On iPhone Duo, pasted and picked images now show in the chat's one-line composer. They were attached but hidden, so paste looked broken.
