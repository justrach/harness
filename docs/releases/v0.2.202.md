# Harness v0.2.202

## Desktop & CI

- **Home configuration & bundled `harness-github-runners` discovery in Settings → Agents → Extensions.** Loads trusted `runtime_plugins` from `~/.harness/settings.json` alongside `<project>/.harness/settings.json` across `ListNativeExtensions` and `InvokeNativeExtension`, and automatically surfaces the bundled macOS `harness-github-runners` panel when local runners are registered under `~/.github-runners/harness-{1,2}/.runner` (`#881`).
- **Signed & notarized macOS releases on sandboxed local M3 workers with cloud fallback.** Routes `release.yml`'s `macos` packaging, Developer ID signing, Apple notarization, and stapling onto `harness-macos-arm64` when the local runner heartbeat is fresh (falling back to `macos-latest` when offline or paused), isolates signing credentials in an ephemeral keychain (`CODESIGN_KEYCHAIN`), updates `parity.yml`, `reauth.yml`, and `testflight.yml` Xcode/SwiftPM macro flags for outer XNU Seatbelt sandboxes, and isolates `engine_start` POSIX spawn tests inside `std.testing.tmpDir` (`#880`).
- **Settings `esc` hints, 2× Retina Member Card finishes, `Default system theme`, and unified `Switch theme`.** Restores visible `esc` hints on Zen Settings' `Back to chats` button and top-right `Close [esc]` pill, upgrades Member Card holographic finishes to display-scale Retina rendering with a clean non-ASCII Seigaiha sky overlay, adds explicit `Default system theme` rows/presets in Settings → Appearance and Theme Studio, and adds `Switch theme` + `Default system theme` in `⌘K`, the Zen sidebar footer, and the View menu (`#882`).

## Verification and scope

- **Workspace and CI suites:** `cargo metadata --locked` verifies all **15** workspace crates resolve to **0.2.202**, alongside `cargo test --locked -p harness-engine --lib native_extensions`, full `harness-nano` `zig build test --summary all` (`1,163` passed, `3` skipped), `zig build test-visual --summary all` (`7/7` steps succeeded), and end-to-end sandboxed `release.yml` macOS packaging, Developer ID signing, notarization, and stapling on local Apple Silicon workers.
