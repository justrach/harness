# Harness v0.2.102

Stable patch release for macOS, Windows and Linux. Includes the changes in
[v0.2.101](v0.2.101.md).

## Accounts

- Codegraff sign-in works on Windows. A stock Windows session has no `HOME`,
  so sign-in stopped with "no home directory to store the Codegraff key in".
  Harness now stores the key under `%USERPROFILE%` when `HOME` is unset or
  empty. A non-empty `HOME` still takes precedence, and the working directory
  is never used.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
