# Harness v0.2.155

A new iOS build on TestFlight. The desktop apps for macOS, Windows and Linux only move to the new version number.

## Crash reports reach Harness without sharing them

- When iOS reports that Harness crashed, hung or used too much CPU or disk, the iPhone app now sends that report to Harness once, so the crash can be found and fixed without you sharing the file. Reports already on your iPhone are sent the first time this build opens while you're signed in.
- A report holds code addresses, the build, the device model and the iOS version, never chat content. It's linked to your account and deleted with it.
- Settings → Crash reports has a **Send to Harness** switch, on by default. Turn it off to keep reports on your iPhone; you can still share one from the list yourself.
