# Harness v0.2.95

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.94](v0.2.94.md) is included.

## CodeGraff PR agent jobs

- Settings → Accounts lists your CodeGraff account's recent PR reviews and
  descriptions: the PR title, repo #PR, and where each run is (Queued,
  Reviewing…, Posting…, Done, or Failed with the reason). While one is still
  working the list refreshes every 20 seconds.
- Cancel a job that hasn't started posting yet; if it's too late, Harness says
  why. Open takes you to the posted review or description.
- Harness posts a notification when a review or description lands or fails,
  even when Settings isn't open. Clicking it opens the review, or the PR. It
  follows your notification settings (including background-only), stays quiet
  for jobs you cancelled, and only runs while you're signed in to CodeGraff.
