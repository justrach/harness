# Harness v0.2.160

Two small changes for desktop.

## A sound when you attach a file

- Pasting, dropping or picking an image or file in the composer plays a short, quiet sound. Settings → Notifications → Attaching files turns it off.

## The pointer stays out of the way while you type

- On macOS, typing sometimes left the mouse pointer on top of the text cursor, after the pointer had passed over the browser pane or a menu. Every keystroke now hides it until the mouse moves.
