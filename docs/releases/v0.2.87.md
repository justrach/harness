# Harness v0.2.87

Pairs with Codegraff `graff` v0.0.302.5. Developer ID signed, notarized and stapled.
Everything in [v0.2.86](v0.2.86.md) is included.

## Faster streaming in long chats

- Unchanged messages keep their rows while a reply streams: per-chunk transcript
  work on a 300-message chat drops from 92µs to 22µs (and from 300µs to 235µs on
  the uncached path). Code-block handle upkeep no longer scales with history.

## Images for ACP agents

- Pasted and dropped images reach ACP agents that accept them (Graff with image
  support, and any agent advertising `promptCapabilities.image`) as image blocks.

## Graff worktrees

- Merge back / Archive / Remove read Graff's exit codes (0 done, 2 kept, 1 failed)
  as well as its ✓ / kept / ✗ markers.

## Anonymous performance stats

- Opt-out stats (launch, conversation load, send, first token, frame times — no
  content, account or paths) now go to `otel.codegraff.com`.
