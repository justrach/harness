# Harness v0.2.185

## Highlights

- **Zeron sidebar & smooth disclosure animations (`apps/nano/src/view_sidebar.zig`, `apps/nano/src/motion_rules.zig`, `apps/nano/lean-proofs/Nano/FrameSchedule.lean`)**:
  - The desktop sidebar's 38-point titlebar cluster hosts back (`←`), forward (`→`), new session (`+`) and view options (`⋯`), proved disjoint and bounded across sidebar widths (`sidebar_titlebar_disjoint_and_bounded`).
  - Project filtering moves into a single full-width rounded pill (`All projects`), session search sits beside the account avatar in the sidebar footer, and `Pinned`, `Sessions`, `Archived` and grouped project disclosures expand and collapse smoothly over `0.18s` `css_ease_out` (`disclosure_opacity_bounded_and_monotone`).
- **Home agent-update island & `harness-updates-v1` protocol (`crates/proto`, `crates/rpc`, `crates/harness`, `crates/engine/src/harness_updates.rs`, `apps/nano/src/agent_updates.zig`, `apps/nano/src/view_agent_updates.zig`, `protocol/desktop/requests.json`)**:
  - Adds the `harness-updates-v1` engine capability and `WatchHarnessUpdates`, `CheckHarnessUpdates`, `ApplyHarnessUpdate`, `CancelHarnessUpdate`, `DismissHarnessUpdate` and `SetHarnessUpdatePolicy` RPCs for managed agent CLIs (`graff`, `claude-code`, `codex`, `pi`, `opencode`, `cursor`).
  - On Home, available agent updates appear in a bottom-anchored pill (`"N agent updates · <Device>"` with overlapping agent marks) that morphs smoothly over `0.20s` into an upward-growing 360-point update card (`update_island_fits_bounds`, `update_island_expands_taller`, `update_stage_monotone_and_bounded`).
- **Narrow split-pane containment (`apps/nano/src/view_transcript.zig`, `apps/nano/src/view_tool_rows.zig`, `apps/nano/src/view_tool_tree.zig`, `apps/nano/src/view_session_footer.zig`)**:
  - Folded tool-group headers, inline tool call rows and the active-chat session footer (`checkout` / `branch`) clamp and step down cleanly inside narrow 3-pane horizontal splits without clipping past the pane border or colliding with the context ring (`tool_group_title_fits_column`, `session_footer_never_overflows_slot`).
