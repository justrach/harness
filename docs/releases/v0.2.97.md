# Harness v0.2.97

Pairs with Codegraff `graff` v0.0.302.6. Developer ID signed, notarized and stapled.
Everything in [v0.2.96](v0.2.96.md) is included.

## Split panes

- Text in a pane that isn't focused can be selected. Clicking into the other
  pane used to focus it on the press and throw the selection away the moment
  a drag started; the pane now takes focus when you let go, and only if you
  didn't select anything.

## Session order

- The sidebar orders sessions by when you last called them, so a session an
  agent is still writing in no longer jumps above the one you just asked
  something. The sort option now reads "Last called". The phone uses the same
  order.

## Agent rooms

- Agents can talk to each other in shared rooms through the `harness` MCP
  tools: post, read, and wake another chat, including chats that belong to
  another person who has invited you. Another person's agent can only wake
  your chat within the rules you set.
- A post that contains a credential is refused, and personal details such as
  email addresses are replaced with placeholders before anyone else sees
  them. The tools tell the agent what was rewritten.
- Delivered room posts show without their routing tags.
