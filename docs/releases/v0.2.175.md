# Harness v0.2.175

`harness-nano` is now the desktop app across macOS, Windows, and Linux, replacing the Rust GPUI client (`crates/ui` and its vendored `zui` / `gpui-component` forks). Built on v0.2.174.

## Desktop (`harness-nano`)

- **Native Zig + NanoUI desktop client**: `harness-nano` is now the sole desktop UI on macOS, Windows, and Linux, with assets and file-icon tables self-contained under `apps/nano/assets`.
- **Session canvases (`⌘T` / `Ctrl+T`) and horizontal splits (`⌘D` / `Ctrl+D`)**: `⌘T` opens a brand-new session canvas ("New session" in the sidebar) while `⌘D` splits the active session side-by-side.
- **Centered new-session starter canvas**: The empty-session hero, starter prompt pills, and composer card sit in a balanced centered column with a warm focus border and glow.
- **Subscription-first model picker**: Model lists group subscription-included models (`ChatGPT Plus/Pro`, `Claude Pro/Max`, `GitHub Copilot`, `Included`) ahead of usage-billed (`Credits`, `API key`) models, with clear section headers.
- **Tab strip and frosted sidebar polish**:
  - Split-pane tabs stay strictly bounded inside their slot partition (`splitSlotPartition` / `otherTabsReserve`) without colliding across adjacent split panes.
  - Active tab cap shadows mask downward interior bleed (`capShadowDownwardBleed`) so no dark line appears across the content seam.
  - Active sidebar pills (`New session`, `New tab`, `Devices`, and active settings sections) use the translucent frosted selection fill (`k.selected`) rather than an opaque card fill over the blurred glass surface.
  - 120fps virtualized settings scrolling (`ui.virtualList`) with Lean 4 formal proofs (`apps/nano/lean-proofs/Nano/StripMenu.lean` and `apps/nano/lean-proofs/Nano/FrameSchedule.lean`).

## iOS

- **Workspace & Settings redesign**: Updated `WorkspaceView`, `SettingsView`, `ChatRowView`, and `ChatScreen` with smooth spring transitions, refined session canvas headers, and clean grouped settings rows.
