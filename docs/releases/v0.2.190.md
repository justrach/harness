# Harness v0.2.190

## Highlights

- **The engine no longer stalls while it runs git.** The engine started `git` and `gh` in a way that made macOS copy the whole engine process (`fork`) each time, holding every memory allocator lock while it did. A busy engine spent seconds at a time at several cores doing that, and the app stopped responding meanwhile. Both now start with `posix_spawn`, with the same PATH as before.

## Verification

`a_login_shell_child_starts_without_fork` counts forks with a `pthread_atfork` handler: the previous construction forks on every spawn, the new one never does. Fifty `git --version` runs went from 50 forks (1.37 s) to none (0.50 s) in a small test process; the difference is larger in the engine, which has hundreds of threads. The engine's `source_control` and `repos` suites pass.
