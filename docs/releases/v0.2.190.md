# Harness v0.2.190

## Highlights

- **Subagents stay out of the iPhone session list.** Worker chats remain available internally for orchestration, but no longer appear as independent sessions in Home, project lists, Archived, or the switcher. They cannot be opened as standalone conversations.
- **Keep the draft you started.** A delayed saved-tab restore no longer replaces a new canvas after you start typing, attach an image, or choose where it should run.
- **Copy the text you selected.** Transcript and composer selection ownership is preserved across real gestures, pane changes, streaming updates, and window changes. Copy follows the current selection rather than a stale highlight.
- **Choose what to do with a link.** Markdown links, URL-only inline code, and expanded tool output offer Open in Harness, Open in browser, and Copy link. Actions are validated against the conversation and visible source that supplied the link.
- **Plain-folder diff feedback.** Working-tree changes explain when the folder is not a Git repository instead of waiting indefinitely. Editing still works without Git, and reviewing a diff does not initialize a repository or change the folder.
- **Desktop retention and rendering.** Integrates the existing renderer and desktop-retention fixes, including native equations, question and queue draft recovery, conversation-owned browser surfaces, and explicit fenced workspace-file saves.

- **The engine no longer stalls while it runs git.** The engine started `git` and `gh` in a way that made macOS copy the whole engine process (`fork`) each time, holding every memory allocator lock while it did. A busy engine spent seconds at a time at several cores doing that, and the app stopped responding meanwhile. Both now start with `posix_spawn`, with the same PATH as before.

## Verification

Synthetic regression checks cover child-session visibility and navigation, startup draft fencing, gesture-driven selection, exact link copying and source ownership, and diff failure/recovery. The integrated desktop passed 946 Nano tests (3 skipped), 28 native-math tests, and seven isolated workflows using the real local engine and native UI with a mock agent. The iOS change passed 42 targeted simulator tests.

`a_login_shell_child_starts_without_fork` counts forks with a `pthread_atfork` handler: the previous construction forks on every spawn, the new one never does. The release also verifies the engine's `source_control` and `repos` paths.

The desktop and iOS distributions are built separately: the tagged release supplies desktop downloads, while the iPhone change is delivered through the internal TestFlight build.
