# Harness v0.2.90

Pairs with Codegraff `graff` v0.0.302.5. Developer ID signed, notarized and stapled.
Everything in [v0.2.89](v0.2.89.md) is included.

## Models

- When an agent offers models from several providers (graff with more than one
  signed-in provider, opencode), the model picker groups them under provider
  headings, with starred models first.

## Tabs and splits

- Each tab and split pane keeps its own agent, model and reasoning. ⌘D and ⌘T
  start from the pane you opened them from.
- ⌘D always splits, even in a narrow window; it no longer opens a new tab when
  the column is tight.
- Ctrl+Tab and Ctrl+Shift+Tab cycle tabs when two or more are open, and still
  step through sessions otherwise. The tab list shows the shortcut.

## Browser

- Clicking back into a chat returns the keyboard to Harness, so Space no longer
  scrolls the page you left.
- Sign-ins in the browser pane now survive a restart. Harness → Clear Browsing
  Data removes them.

## Appearance

- The window is frosted by default again. Settings → Appearance has a single
  Frosted glass switch.

## Sessions

- While an agent waits on your answer, the working line hides, and the turn
  timer no longer counts the time you spend deciding.
- If a resumed graff chat can't switch to the model you picked, it offers to
  start a new chat on that model or keep the restored one, with your prompt
  carried over.
- With graff builds that report subagent progress, the working line lists each
  running subagent's latest steps.

## Attachments

- Images you attach are sent to ACP agents that accept images on every turn,
  not only the first, so the agent no longer has to open the file itself.
- Only files in this device's uploads folder are ever attached; other paths in
  a prompt stay as plain text.

## Security

- The Harness refresh credential is now encrypted rather than only signed.
  Older credentials still work for one more refresh.
- Sync connections send their token in an `Authorization` header instead of
  the URL (#10).

## Settings

- Long hints in Settings → Agents wrap inside their card.
