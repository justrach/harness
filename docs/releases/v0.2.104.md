# Harness v0.2.104

Stable release for macOS, Windows and Linux. Includes the changes in
[v0.2.103](v0.2.103.md).

## ChatGPT reconnect

- Reconnect ChatGPT directly inside the chat instead of leaving for Settings.
  The card shows sign-in progress on the computer running the conversation,
  with Cancel, retry and a clear reconnected state.
- After sign-in is verified, **Resume conversation** continues the same chat
  on its saved agent and model. It sends only when clicked, preserves drafts
  and attachments, and does not automatically resend the failed prompt.
- Multiple chats and devices share one pending sign-in for the same host,
  route and account. Opening another viewer no longer cancels an approval
  already in progress; only an explicit Cancel ends it.
- Sign-in actions for the new ChatGPT plan endpoint use **Continue with
  ChatGPT**, following the current Sign in with ChatGPT guidance. Legacy and
  other provider routes are unchanged.
- A conditional note explains that a recent password reset or Advanced
  Account Security enrollment, including Daybreak, may require a fresh
  sign-in. Harness does not infer these circumstances or suggest disabling
  account security.

This improves recovery after a sign-in failure. It does not claim to fix
upstream token renewal after the one-hour access-token lifetime.

## Cloud and devices

- Cloud sandbox controls are available in Settings, with a cloud entry in the
  device picker.
- Offline devices can be removed, and the Codegraff account controls use one
  Sign out action.

The mobile source also includes reconnect/resume recovery and a fix for
transcript layout crashes. Mobile app and terminal-client packages are
 distributed separately from this desktop release.
