# Harness v0.2.188

## Highlights

- **Windows portable builds start their engine when Nano opens directly.** Keep `harness.exe` and `harness-nano.exe` together in the extracted folder. Either executable now finds the bundled engine, starts it when needed, and connects Accounts and the new-session screen instead of leaving them at “not connected.”
- **Windows executable discovery follows Windows conventions.** Nano looks for `harness.exe` beside itself before searching the application locations and uses `;`-separated PATH entries with the `.exe` suffix. The explicit `HARNESS_NANO_ENGINE_BIN` override remains first, and existing macOS discovery is unchanged.

## Verification

- The Windows portable discovery regression test fails on v0.2.187 and passes with this release.
- All 11 `engine_start` tests pass, including engine startup, retry, replacement, and shutdown behavior.
