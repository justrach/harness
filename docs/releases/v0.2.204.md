# Harness v0.2.204

## Codegraff Orchestrator Mode & Usage Meter

- **Orchestrator mode control & composer account usage meter (`#886`):** Adds Codegraff orchestrator mode selection alongside live composer account usage metering and quota display across the desktop workspace and ACP adapter.
- **Graff command selection & retry safety (`#761`):** Preserves Graff slash-command selection intent across adapter invocations and prevents contextless retries when an invocation is rejected or incomplete.

## Desktop Workspace & Navigation

- **Archived chat browsing separation (`#840`):** Keeps archived chat browsing separate from the active workspace selection so viewing archived threads no longer disrupts live workspace tabs.
- **Active-chat Done badge clearing (`#827`):** Automatically clears the `Done` badge when replies are viewed in the active chat.
- **`Cmd+D` project inheritance & new-tab selection (`#791`):** Inherits the active project when opening a new tab with `Cmd+D` and selects the newly opened tab consistently.

## iOS Voice Mode & Performance

- **Hands-free Session Voice Mode & Live Activity voice orb (`#861`):** Introduces hands-free Session Voice Mode with an interactive voice session sheet and Live Activity voice orb indicator.
- **Main-thread responsiveness, scrolling reuse & lazy system frameworks (`#771`, `#772`, `#773`, `#774`):** Moves session document locking off the main actor, reuses transcript text views while scrolling, releases catch-up diff state memory promptly, and lazy-loads `PhotosUI` and `AuthenticationServices` to trim launch time.

## CI & Tooling

- **Cargo-aware CI scope gating (`#885`):** Adds `scripts/ci-changed-scopes.py` so non-Rust changes and version-bump-only `Cargo.toml`/`Cargo.lock` edits skip unneeded heavy Rust and Android NDK CI suites while keeping Zig Nano UI tests active.
- **Rich composer queue-edit fixture alignment (`#819`):** Updates the rich composer delivery integration test fixture to match execution ownership cleanly.
