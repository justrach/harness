# Harness v0.2.145

Desktop update for macOS, Windows and Linux.

## See when the final answer is ready

- Completed assistant replies now have a muted **Worked for …** heading and a thin divider before the final answer, separating the result from progress updates and tool activity.
- When a conversation has no recorded duration, the heading says **Final answer** instead of estimating a time. Replies that are still streaming, interrupted, or waiting on work do not get the new completion marker.
- Compact mode keeps its expandable work history and shows the divider without repeating the heading. Detailed mode keeps its existing activity layout. Text selection and copying are unchanged.
