# Harness v0.2.113

Stable desktop patch release for macOS, Windows and Linux.

## Dictate into the composer

- A microphone button in the composer turns speech into text as you talk,
  using the voice built into the Codex CLI and your Codex sign-in. Words
  appear in the draft as they are recognised, so you can edit before sending.
- Click the microphone again, or send, to finish. Anything still being
  recognised is kept.
- The button appears only where Codex's voice helper is installed. A Codex
  CLI without voice support leaves the composer as it was.

## Servers update themselves

- Servers installed with
  `curl -fsSL https://edge.codegraff.com/install.sh | sh` now install new
  releases on their own, but only while no chat is running and no terminal
  is open. Until then they wait and check again every few minutes.
- A server run as a service is restarted by its service manager. One started
  by hand, in a shell, tmux or a container, shuts down cleanly and restarts
  itself into the new version.
- Servers that aren't signed in check for updates too.
- Set `HARNESS_AUTO_UPDATE=0` in `~/.harness/env` to update only when you run
  `harness update`, as on the desktop app.

## codedb comes with Harness

- The macOS app now includes codedb, the code search tool agents are often
  told to use, so it works from the first launch, offline included.
- Harness keeps it current from codedb's releases, checking hourly like
  graff, and right after graff updates. Each download is checked against
  the release's checksums before it is installed.
- Servers and other computers without the app bundle get codedb about 30
  seconds after Harness starts.
- A codedb you installed yourself is still the one agents use. Set
  `HARNESS_CODEDB_AUTO_INSTALL=0` to stop Harness downloading it.

## Phones

- iPhone: the person button on Home opens **Profile**, with your account,
  usage, sign-out and account deletion. The gear opens **Settings**, which
  now holds only app preferences. Lists follow the app's theme colours.
- iPhone: the model, branch and folder pickers for a new session or space are
  searchable, and they no longer empty and reload while you're choosing.
