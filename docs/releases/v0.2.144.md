# Harness v0.2.144

Desktop hotfix for macOS, Windows and Linux.

## Choose what happens when you close a chat

- Closing a chat with **⌘W** now asks every time: **Just close it**, **Archive
  it**, or **Cancel**. A previous choice or saved archive-on-close preference
  no longer skips the question.
- **Just close it** removes the tab or pane but keeps the chat in the sidebar.
  **Archive it** also moves an idle chat to the archived shelf, provided it is
  not still open elsewhere. Running chats and chats waiting for input are
  never archived by closing them.
- Each answer applies only to that close. It does not change the saved
  archive-on-close setting for tab and pane **✕** buttons. **Cancel** or
  **Escape** leaves the chat open.
- **⌥⌘W** remains the direct close-without-archiving shortcut. On Windows and
  Linux, the normal chat-close shortcut is **Ctrl+Shift+W**, and the direct
  close-without-archiving shortcut is **Ctrl+Alt+W**.

File and other non-chat surfaces keep their existing close behavior. Closing
an empty chat canvas does not close the application window.
